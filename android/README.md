# 집 안 사진 메타데이터 전송 앱

Galaxy S23 Ultra, Android 16, One UI 8.5에서 사진의 촬영 정보만 기존 PC 자료 수집 대기함으로 보냅니다. Android 14 이상을 대상으로 하며 개발용 APK입니다. 원본 접근 시험에서는 PC JPEG와 일반·원본 요청의 전체 SHA-256·촬영 시각·GPS가 일치했습니다. Android·Chrome·파일 제공자 중 웹 GPS 가림을 수행한 주체는 확정하지 않았습니다.

## 사용 흐름

1. PC에서 관리자 프로그램에서 **모바일 연동 서버 실행**을 누릅니다. 집 안 HTTPS 주소는 `https://192.168.75.181:8443`이며 인터넷 포트포워딩을 추가하지 않습니다.
2. PC 자료 수집 → 내 사진 → 집 안 휴대폰 연결에서 연결 코드를 발급합니다. 앱의 기기 이름과 코드에 입력하고 PC 연결을 누릅니다. 코드는 10분·일회용, 세션은 최대 30일입니다.
3. 앱에서 사진·촬영 위치 접근 허용으로 사진 접근·선택 사진·사진 속 위치 권한을 한 번에 요청합니다. 필요한 사진만 허용할 수 있습니다. 이미 전체 사진을 허용했다면 앱의 사진 권한 설정 열기에서 변경할 수 있습니다.
4. 사진을 12장씩 미리 보며 체크합니다. 최대 500장·한 장 32MB의 JPEG·PNG를 지원합니다. 선택 목록과 현재 탐색 목록은 분리합니다.
5. 선택 정보 읽기로 원본 요청의 촬영 날짜·시각·시간대·GPS를 읽습니다. 읽기 실패·날짜/GPS 누락·선택 파일 내용 중복은 구분합니다. 현재 위치·파일명·수정 시각으로 값을 채우지 않습니다.
6. 선택 목록에서 값을 확인한 뒤 확인한 정보 전송을 누릅니다. 완료·중복·실패를 사진별로 표시하고 실패 항목을 재시도할 수 있습니다. PC에서 삭제·등록한 자료도 재전송으로 되살리지 않습니다.
7. PC 대기함에서 종·성장 단계 등을 검수한 뒤 직접 관찰로 등록합니다. 앱 수신만으로 관찰을 생성하지 않습니다.

사진 원본·미리보기·기기 URI는 전송하지 않습니다. 미리보기는 현재 페이지 중심으로 읽고 메모리 캐시 상한은 8MB입니다. 사진 정보는 한 장씩 읽고 전송 간격은 최소 700ms로 제한합니다. 429 응답 시 남은 전송을 중단하고 앱에서 60초 동안 재시도를 제한합니다. 응답이 끊긴 자료는 재시도 시 기존 서버의 파일 해시 중복 확인을 사용합니다.

## 연결·보관 범위

- 통신 대상은 코드에 고정한 내부 주소의 `/m/api/login`, `session`, `logout`, `photos`뿐입니다. Wi-Fi 네트워크에 연결을 묶으며 모바일 데이터로 자동 전환하지 않습니다. VPN 활성 상태에서는 연결을 중단합니다. 리다이렉트·평문 HTTP는 허용하지 않습니다.
- Android의 INTERNET·ACCESS_NETWORK_STATE 권한은 집 안 통신에 필요합니다. 외부 조회 서버와 별개의 입력 경로이며 외부 공인 인증서 발급과도 독립적입니다.
- PC 공개 CA 인증서를 앱 리소스로 빌드해 해당 내부 주소에만 신뢰를 지정합니다. 기본 인증서 체인·호스트 검증을 유지합니다. 연결 코드는 URL에 넣지 않으며 요청 본문·쿠키·GPS를 로그로 출력하지 않습니다.
- 기존 Secure·HttpOnly·SameSite=Strict 세션 쿠키를 사용하고 토큰과 만료 시각만 Android Keystore AES-GCM으로 암호화해 백업 제외 영역에 보관합니다. 로그아웃은 서버 세션도 해제합니다. 이 기기의 연결 정보 지우기는 로컬 쿠키만 지우므로 PC 연결 관리에서 이전 세션을 따로 해제할 수 있습니다.
- 사진 선택·메타데이터·미리보기는 메모리에만 두며 화면 회전 시 유지합니다. 앱을 완전히 종료하거나 프로세스가 종료되면 사라집니다. 앱을 벗어나면 남은 작업을 중단합니다. 진행 중 요청의 PC 저장 여부는 응답을 못 받으면 확정하지 않습니다.
- 앱 파일은 클라우드 백업과 기기 이전에서 제외합니다. 기기 대기함·백그라운드 자동 수집·HEIC·동영상·사진 원본 전송은 구현하지 않았습니다.

## 개발 환경과 빌드

Android Studio Rabbit 2 2026.2.2, SDK 36, Build Tools 36.0.0을 사용합니다. Gradle 9.6.0·Android Gradle Plugin 9.5.0·ExifInterface 1.4.2·Activity 1.12.4를 고정합니다. Activity는 화면 회전 시 선택 상태를 유지하는 ViewModel에 사용합니다. 네트워크·암호화는 Android 기본 API이며 별도 통신 라이브러리를 사용하지 않습니다. 테스트는 JUnit 4.13.2·AndroidX runner 1.7.0·ext junit 1.3.0입니다.

SDK 경로는 Git 제외 `local.properties`에 둡니다. 공개 CA는 기본적으로 프로젝트의 `data/집안사진전송인증서.crt`에서 읽습니다. 다른 위치라면 `-PlanCaFile=공개인증서절대경로`를 지정합니다. 빌드 시 산출물의 `generated/lan-ca/raw`에만 복사합니다. CA 비밀키·개인 인증서·SDK 경로·세션·빌드 산출물은 Git에 넣지 않습니다.

Windows의 한국어 경로에서는 Gradle 테스트 실행기가 클래스 로딩에 실패하므로 산출물만 영문 경로로 지정합니다. 소스 위치는 그대로 유지합니다.

```powershell
$probeOutput = Join-Path $env:LOCALAPPDATA 'ButterflyArchive/android-transfer-build'
.\android\gradlew.bat -p android "-PprobeBuildDir=$probeOutput" assembleDebug testDebugUnitTest lintDebug
```

APK는 `$probeOutput/outputs/apk/debug/app-debug.apk`에 생성됩니다. 연결된 휴대폰에 설치하려면 SDK Platform Tools의 adb를 사용합니다. 최초 PC 인증 허용은 사용자가 휴대폰에서 직접 확인합니다.

합성 사진·암호화·JSON·화면 재생성 검사는 다음과 같습니다. 개인 사진이나 PC DB는 사용하지 않습니다. 검사 도구가 시험 후 앱을 정리할 수 있으므로 실제 사진 선택 작업 중 실행하지 않습니다.

```powershell
.\android\gradlew.bat -p android "-PprobeBuildDir=$probeOutput" connectedDebugAndroidTest
```

실제 집 안 Wi-Fi·HTTPS의 미인증 요청 차단까지 확인하려면 집 안 서버 실행 후 `-Pandroid.testInstrumentationRunnerArguments.verifyLan=1`을 추가합니다. 이 검사는 세션 조회만 요청하고 사진 정보나 코드를 전송하지 않습니다.

## 현재 확인 범위

- Android 단위 테스트 6개, 실기기 검사 6개, 모바일 API 시험 DB 검사 10개가 통과했습니다. 빌드와 린트도 통과했으며 린트 오류 0개·경고 11개가 남아 있습니다. 버전 안내·아이콘·표시 문자열 관련 경고이며 숨기지 않았습니다.
- 실제 S23 Ultra에서 일반·원본 사진의 촬영 정보 추출, 위치 권한이 없을 때 종료 대신 안내 표시, 합성 사진의 GPS 없음·원본 불변, 세션 암호화·변조 거부, JSON 전송 형식, 화면 재생성 후 선택 목록 유지, 내부 인증서 신뢰와 미인증 401을 확인했습니다.
- 실제 사진 한 장의 연결 코드 로그인·전송·PC 대기함 표시·DB 재조회를 확인했습니다. 실제 Wi-Fi 단절·다량 선택·장시간 사용·기기별 권한 거부 후 재허용은 추가 확인 대상입니다. API의 잘못된 입력·요청 제한·만료·저장 실패·재전송·직접 관찰 등록은 시험 DB 검사와 구분합니다.
