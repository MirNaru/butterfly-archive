집 안 사진 전송

사진의 촬영 정보를 PC 자료 수집 대기함으로 보냅니다.

휴대폰 연결

집 Wi-Fi에 연결하고 PC의 자료 수집 → 내 사진에서 연결 코드를 발급해 주세요.

사진 선택

JPEG·PNG의 메타데이터만 전송합니다. 사진 원본은 전송하지 않습니다. HEIC·동영상은 아직 지원하지 않습니다.

갤러리 선택에서 GPS가 보이지 않으면 원본 파일에서 선택을 사용해 내 파일 → 내장 저장공간 → DCIM → Camera의 같은 사진을 골라 비교해 주세요. 파일 선택 화면은 브라우저에 따라 다를 수 있고 위치 정보가 유지된다고 보장하지는 않습니다. 원본 사진은 휴대폰에서만 읽으며 전송하지 않습니다.

사진을 읽는 동안과 전송 중에는 이 화면을 켜두세요. 사진 파일에 GPS·촬영 시각이 없으면 복원하지 않습니다.

전송한 정보는 PC에서 종과 성장 단계 등을 검수한 뒤 직접 관찰로 등록합니다. 같은 관찰의 사진은 PC에서 묶어서 등록할 수 있습니다.

사진을 선택한 뒤 각 항목의 사진 진단을 펼쳐 주세요. 파일 크기·SHA-256·EXIF·GPS 태그·읽기 오류를 이 기기에서만 표시합니다. 전송 버튼을 누르지 않아도 확인할 수 있습니다. 같은 해시는 같은 파일 내용이며, 다른 해시만으로 GPS가 가려졌다고 확정할 수는 없습니다. GPS 태그 1·2는 위도, 3·4는 경도 항목입니다. 오류가 있으면 항목 없음으로 단정하지 마세요.
