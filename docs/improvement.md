# 미구현 및 확인 사항

현재는 종 수동 등록·목록, 탐사·종별 기록 등록·수정·목록·상세 조회, 관찰·탐사 통합 검색, 직접·간접 출처 입력, 통합 관찰 기록표와 하단 탭을 구현했습니다. 나비 도감의 한살이 도표·습성 메모와 환경 태그 등록·수정·검색도 구현했습니다. 사진 검사·정보 등록·선택 원본 보관·기록 연결과 소장·취득 경로 관리도 구현했습니다. 탐사·관찰의 휴지통 삭제·복구도 구현했습니다. 네이버 지도·주소 선택과 ASOS 기상 조회·저장을 구현했습니다. 네이처링 Chrome 확장 수집·DB 전송·사용자 선택 등록, 원문 기상 표시, 관찰 상세 팝업 내 수정과 20사례 기준 한살이 상자 수염도 구현했습니다. 아래는 미구현 작업과 아직 결정되지 않은 항목을 관리하는 목록입니다. 해결 시 현재 사양 문서에 반영하고 이 목록을 정리합니다.
도감 동정 문장의 과·아과별 템플릿 정리와 사용자 검토를 진행했습니다. 이후 자료 보완도 기존 용어·부위·의미를 보존하며 별도 검토합니다. 모든 생물학적 사실을 검증했다는 뜻은 아닙니다.

## 사용 흐름 점검 범위

- 별도 시험 DB와 외부 API를 끈 화면 서버에서 새 탐사 등록 → 합성 JPEG 촬영 정보 검사·날짜 적용·정보 등록 → 탐사 저장 → 검색의 정상·빈 결과 → 관찰 상세 팝업 내 단계·개체 수·메모 수정 → 개별 관찰 휴지통 이동·복구 → 화면 새로고침 후 재조회를 확인했습니다. 수정 내용과 사진 정보 연결을 보존했습니다.
- 관련 API 검사 70개와 검색·필터 검사 12개를 통과했습니다. API 검사에는 잘못된 입력·저장 실패·편집 충돌·기상 조회 실패 시 기존 자료 보존·삭제 후 연결 보존·재시작 후 조회가 포함됩니다. 실제 개인 DB와 실제 외부 API를 사용하지 않았습니다.
- 이번 화면 점검은 시험 기록 한 건의 흐름을 확인한 것입니다. 수백 건 화면 성능, 실제 지도 SDK와 기상청 추가 호출, 서로 다른 사진 1400장의 처리 성능은 이번 검증에 포함하지 않았습니다. 한살이의 시기 밖 실제 자료 확인도 별도로 남아 있습니다.

## 보류 및 후속 범위

- 도감 기간의 일 단위 경계와 초중·중후 편집을 구현했습니다. 제공 자료가 없는 종의 기간 입력과 도감명·판본 확인은 남아 있습니다. 관찰 날짜는 보정하지 않습니다.

- 환경 태그 이름 변경·통합·삭제 관리와 관찰별 구조화된 생태 항목은 후속 범위입니다. 현재는 태그 선택 해제만 지원하며 기억된 이름은 유지합니다. 태그는 자동으로 습성·기상 수치로 변환하지 않습니다.

- 근거 불명의 기존 채집 가중치는 원본만 보존하고 기본 추천에 사용하지 않습니다. 분포 상수와 과거 연도 기준의 근거는 미확인입니다.
- 표 셀 직접 편집, 일괄 붙여넣기, 대량 수정은 별도 승인·검증 대상으로 둡니다.
- 전체 변경 이력 열람, 자동 백업, 엑셀 내보내기의 구체 범위는 확정하지 않았습니다.
- 등록 요청 도중 응답이 끊긴 경우 서버에 저장되었을 수도 있으므로 목록을 조회한 뒤 재시도하도록 안내합니다. 요청 중복 방지 키는 아직 구현하지 않았습니다.
- 탐사 목록은 일괄 조회 방식이며 합성 자료 300·1000건에서 측정했습니다. 1000건 수정창 진입·상세 닫기는 자동화 포함 중앙값 0.69초·0.64초로 추가 개선 여지가 있습니다. 페이지 처리·실제 지도 SDK·장시간 메모리는 후속 검증 대상입니다.
- 탐사·관찰 수정과 휴지통 삭제·복구를 구현했습니다. 휴지통 항목별 완전 삭제도 구현했습니다. 휴지통 전체 삭제도 구현했습니다. 소장·종 정보 삭제는 후속 범위입니다.
- 네이처링 수집·선택 등록은 구현했습니다. iNaturalist API와 논문 서지 수집·간접 관찰 사례 등록은 구현했습니다. Gemini 기반 웹 검색과 직접 확인한 원문 대기함은 별도 기능으로 구현했습니다. 자동 진위 검증·출현 예측은 후속 단계입니다. 모바일 사진 정보 전송은 첫 버전을 구현했으며 HTTPS 발급·실기기 검증이 남았습니다.
- Starlette TestClient의 httpx 사용 중단 예정 경고가 테스트에서 계속 발생합니다. 의존성 변경 없이 테스트는 통과하며, 대체 패키지 적용은 별도 검토 대상입니다.

네이처링 확장은 사용자가 시작한 연속 수집과 로컬 전송을 지원합니다. 수집 원문은 대기함에 보존하고 체크한 항목을 간접 관찰로 등록합니다. 게시자가 위치를 숨겼거나 위치가 미입력·빈칸이거나 공개 좌표 쌍이 없는 자료는 수집에서 제외합니다. 등록 후 대기 목록에서 숨기며 관찰 삭제·복구는 휴지통에서 처리합니다. 단계는 도감 기간에 따른 추정과 수동 확인을 구분하며 자동 진위 검증은 구현하지 않았습니다.

## 과거 검증 기록의 읽기 기준

아래 측정·테스트 건수는 당시 코드와 자료의 결과입니다. 최신 전체 재검증으로 해석하지 않습니다. 경량화한 원시 자료는 `data/maintenance-archives`의 manifest.json에서 원래 프로젝트 상대 경로를 검색하고 해당 ZIP을 별도 폴더에 풀어 확인합니다. 현재 실행 로그·권한 복구 파일은 원래 위치에 보존합니다.

## 화면 성능 개선 검증

- Windows PC(Ryzen 7 5800X), Codex 브라우저 1280×720, Vite 개발 모드에서 동일한 합성 관찰 300·1000건과 282종으로 비교했습니다. 아래는 각 5회 중앙값이며 자동화 명령과 DOM 결과 확인 시간을 포함합니다. 실제 입력·화면 그리기 지연만을 측정한 값은 아닙니다.

| 동작 | 300건 이전 → 이후 | 1000건 이전 → 이후 |
| --- | --- | --- |
| 초기 표시 | 0.630 → 0.579초 | 1.520 → 0.823초 |
| 상세 열기 | 0.373 → 0.270초 | 0.819 → 0.301초 |
| 수정창 진입 | 0.354 → 0.364초 | 0.776 → 0.691초 |
| 상세 닫기 | 0.343 → 0.340초 | 0.772 → 0.638초 |
| 도감 전환 | 1.173 → 0.363초 | 1.408 → 0.406초 |
| 표 전환 | 0.336 → 0.303초 | 0.604 → 0.436초 |

- 1000건 탐사 API 중앙값 316.5 → 37.6ms, 저장 기상 API 202.9 → 13.5ms입니다. 탐사 SELECT는 7001 → 5회, 저장 기상 SELECT는 901 → 1회이며 두 경로 모두 DB 연결 한 개를 사용합니다. 300·1000건의 탐사·저장 기상 응답은 변경 전 저장본과 완전히 같았습니다.
- 도감 전체 282종 행·텍스트는 유지하고 화면 주변 그래프만 생성합니다. 최초 화면의 그래프 282 → 6개, 전체 DOM 요소 약31493 → 8826개를 확인했습니다. 세로 이동 뒤 해당 구간 그래프 9개, 가로 스크롤 양 끝 이동, 편집 저장 후 탭을 바꿨을 때 최신값 표시를 확인했습니다.
- 1000건 검색 재측정은 약443ms, 해제260ms, 날짜 정렬229ms였습니다. 검색에는 행 수 도달 대기가 추가되어 이전 측정과 직접 비교에 한계가 있으므로 검색 성능 개선을 주장하지 않습니다.
- 실제 개인 DB를 테스트로 수정하지 않았고 외부 API 호출은 0회입니다. 실제 지도 SDK, 사진1400장, 장시간 메모리·프레임 속도, 배포 빌드 실행 성능은 미검증입니다. 측정 원본은 Git 제외 경로 `.tmp/performance-20261030-run2`의 이전·이후 보고서에 보관합니다.

논문 수집은 Crossref를 기본으로 사용하며 KCI는 선택 연동입니다. KCI 실제 키를 사용한 응답 검증과 대량 논문 목록 성능은 별도 확인 대상입니다. 선택한 공개 PDF의 제한된 텍스트에서 Gemini 서지 후보를 받을 수 있습니다. 추천·본문 전체 분석·관찰 자동 추출은 후속 범위입니다.

로컬 PDF 직접 추가·원본 보관·쪽별 텍스트 열람을 구현했습니다. PDF에서 생물학적 관찰 사례를 자동 해석하는 기능, OCR, AI 요약·추천은 구현하지 않았습니다. 파일명·첫 쪽 DOI로 얻는 서지정보는 원문 확인이 필요하며 발표일을 파일 생성일로 대체하지 않습니다.

- KIMR 연동은 기온만 조회합니다. 저장된 ASOS 일자료의 강수량과 평균풍속은 활동 적합도에 반영합니다. KIMR 예보의 강수량·풍속 일 집계와 입력 시각별 기상 반영은 후속 범위입니다.
- 과거 ASOS 일자료 수집 명령은 구현했습니다. 운영 DB에서 서울 108을 제외한 96개 ASOS 관측소의 과거 일자료 240,244건을 추가했습니다. 대상 기간 중 미저장 5,878일과 평균기온 결측 237일은 남아 있습니다. 적산온도 보정 성능은 별도 평가가 필요합니다. 연속 기온 자료가 부족하거나 이후 연도 평가에서 보정 효과가 확인되지 않으면 날짜 KDE를 사용합니다.
- KIMR 기온 예제 응답 확인과 실제 지도 검증은 별개입니다. 실제 지도에서 우클릭부터 결과 막대 표시까지 GDD 적용과 날짜 KDE 대체 경로를 각각 확인하는 작업이 남아 있습니다.
- 종별 기준온도와 활동 계수의 생물학적 검증, 종별 이동성 편집은 후속 작업입니다.
