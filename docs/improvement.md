# 미구현 및 확인 사항

현재는 종 수동 등록·목록, 조사·종별 기록 등록·목록·상세 조회, 간단 검색, 조사 표와 하단 지도·표 탭을 구현했습니다. 지도는 연동 대기 화면입니다. 아래는 미구현 작업과 아직 결정되지 않은 항목을 관리하는 목록입니다. 해결 시 현재 사양 문서에 반영하고 이 목록을 정리합니다.

## 미구현 작업

| 항목 | 상태 | 선행 조건 |
| --- | --- | --- |
| 조사·종별 기록 수정·삭제 | 미구현 | 개별 값 상속·삭제 복구 규칙과 변경 계획 확인 |
| 표의 고정 열·정렬 선택·종 및 소장 목록 전환 | 미구현 | 기본 조사 표와 간단 검색은 구현 |
| 지도 및 주소 연결 | 요구 확정, 서비스 미정 | 비용 발생 차단 검증과 위치 전송 범위 승인 |
| 상세 필터·태그·생태 정보 필드 | 미구현 | 기본 검색과 특정 종 미발견 기록은 구현 |
| 엑셀 반입 | 미구현 | 원본 보존, 변환 미리보기, 백업·반입 승인 |
| 소장·취득 경로 관리 | 최소 기능 설계 확정, 미구현 | 종 식별과 미확인 상태 지원 |
| 사진·촬영 시각 후보 | 설계 확정, 미구현 | 파일 보존·검증·저장 실패 처리 설계 |
| 가로 출현 참고 도표·관찰점 | 표시 방향 확정, 미구현 | 단계와 출처 구분 |
| 상자 수염 통계 | 방향 합의, 세부 규칙 검토 중 | 아래 통계 규칙 결정 |
| 과거 기상 | 요구 확정, 서비스 미정 | 무료 접근·제공 기간·자료 항목 검증 |
| 백업·복원·삭제 복구 | 방향 합의, 세부 방식 검토 중 | 형식·저장 위치·복구 규칙 결정 |

## 구현 전에 결정하거나 확인할 내용

| 항목 | 담당과 처리 |
| --- | --- |
| 구매 자료의 구분 | 사용자가 나중에 확인합니다. 그전에는 취득 경로 미확인으로 저장합니다. |
| 소지하지 않은 체크의 의미 | 원본 체크 상태를 보존합니다. 미체크를 과거 미관찰로 해석하지 않습니다. |
| 식물명 중복·종명 정리 | 개발자가 후보를 제시하고 사용자 확인 후 처리합니다. 자동 병합하지 않습니다. |
| 조사 기본값 변경의 전파 | 개별 위치·날짜를 보존하는 방식과 사용자에게 미치는 영향을 첫 구현 계획에서 설명합니다. |
| 동일 종·성별·단계별 기록 분리 | 혼합 기록과 세부 수량 입력의 관계를 입력 시안에서 확인합니다. |
| 상자 수염 규칙 | 관찰 집계 단위, 중복 제거, 최소 자료 수, 수염·이상값, 지역·연도·발생 차수·연말 처리 규칙을 결정합니다. |
| 지도 무료 조건 | 개발자가 확인합니다. 결제 등록·유료 사용은 승인된 범위가 아닙니다. 보장 불가 시 대안을 사용자와 결정합니다. |
| 기상 서비스 | 개발자가 과거 조회 기간·관측소·항목·단위·누락·일별 요약·인증 방식을 조사합니다. |
| 사진 저장 | 허용 형식·크기, 저장 위치, 중복 파일과 실패 시 정리 방식을 구현 계획에서 제시합니다. 원본 자동 삭제는 하지 않습니다. |
| 백업·복원 | DB와 사진을 함께 보존합니다. 파일 형식·대상·덮어쓰기 방지와 복구 절차를 구현 전 확인합니다. |
| 삭제 복구 | 휴지통 또는 다른 복구 방식은 아직 확정하지 않았습니다. 파괴적 삭제를 기본으로 구현하지 않습니다. |

## 보류 및 후속 범위

- 근거 불명의 기존 채집 가중치는 원본만 보존하고 기본 추천에 사용하지 않습니다. 분포 상수와 과거 연도 기준의 근거는 미확인입니다.
- 표 셀 직접 편집, 일괄 붙여넣기, 대량 수정은 별도 승인·검증 대상으로 둡니다.
- 전체 변경 이력 열람, 자동 백업, 엑셀 내보내기의 구체 범위는 확정하지 않았습니다.
- 등록 요청 도중 응답이 끊긴 경우 서버에 저장되었을 수도 있으므로 목록을 조회한 뒤 재시도하도록 안내합니다. 요청 중복 방지 키는 아직 구현하지 않았습니다.
- 조사 목록은 현재 전체 조회 방식입니다. 수백 건 성능 측정과 필요 시 페이지 처리는 다음 검증 대상입니다.
- 현재 UI의 상세 등록 정보는 저장 후 조회할 수 있지만 편집·삭제 기능은 아직 없습니다. 실제 개인 자료를 많이 넣기 전 수정·복구 기능을 먼저 완료하는 것이 좋습니다.
- 외부 수집·자동 검증·논문 업데이트·출현 예측·모바일 원격 접속은 후속 단계입니다.
- Starlette TestClient의 httpx 사용 중단 예정 경고가 테스트에서 계속 발생합니다. 의존성 변경 없이 테스트는 통과하며, 대체 패키지 적용은 별도 검토 대상입니다.
