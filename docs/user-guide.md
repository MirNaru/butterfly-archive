# Butterfly Archive 사용자 매뉴얼

Butterfly Archive는 나비 관찰 기록을 지도와 도감에서 찾아보고, 수집 자료를 검수해 기록으로 남기는 프로그램입니다.

## 심사자용 읽기 전용 데모

1. [Butterfly Archive 데모](https://archive.mirnaru.kro.kr/)를 엽니다.
2. 조회 코드가 표시되면 제출 안내에 기재된 코드를 사용합니다.
3. 지도에서 위치를 고르거나 기록표에서 종과 날짜를 확인합니다. 도감에서 종의 생태와 한살이 정보를 살펴봅니다.

데모는 관리자가 갱신한 시점의 사본을 보여줍니다. 도메인에 연결되지 않으면 제출 PDF의 화면 캡처를 참고해 주세요.

## 운영 PC에서 시작하기

프로젝트 폴더에서 `ButterflyAdmin.exe`를 실행합니다. **PC 입력 서버 실행**을 누르면 브라우저에 입력 화면이 열립니다. 왼쪽 로그에서 실행 결과를 확인할 수 있습니다.

| 버튼 | 용도 |
|---|---|
| PC 입력 서버 실행 | 기록 입력과 검수 화면 열기 |
| 읽기 전용 서버 실행 · 사본 갱신 | 조회용 사본을 한 번 갱신하고 도메인 조회 시작 |
| 모바일 연동 서버 실행 | 집 안 네트워크의 Android 전송 연결 시작 |
| 인증서 갱신 확인 | 공인 HTTPS 상태와 인증서 발급일·만료일 확인 |

서버 상태는 초록 **실행 중**, 노랑 **켜는 중**, 빨강 **꺼짐**으로 표시됩니다. 인증서에는 만료 14일 전 점검일이 표시됩니다. 갱신 시점은 Caddy가 관리합니다.

## 기록과 도감 사용하기

- **지도**에서 관찰 위치를 확인하고 핀의 기록을 엽니다.
- **기록**에서 종, 장소, 날짜를 검색합니다. `검수 필요`를 입력하면 도감 분포나 출현 시기를 확인할 후보를 볼 수 있습니다.
- **나비 도감**에서 종 이름을 더블클릭하면 기본 정보가 열립니다. **심층 분석**에서는 어른벌레 관찰 분포를 연도와 지역별로 비교합니다.
- **자료 수집**에서 네이처링·iNaturalist 자료를 검수한 뒤 선택한 항목을 등록합니다. **논문 탐색**에서는 논문을 검색하거나 공개 PDF를 추가하고 서지 정보를 확인할 수 있습니다.

## Android에서 촬영 정보 보내기

1. PC에서 **모바일 연동 서버 실행**을 누르고, 휴대폰을 PC와 같은 집 안 네트워크에 연결합니다.
2. PC의 **자료 수집 → 내 사진**에서 Android 연결 안내와 연결 코드를 확인합니다.
3. Android 앱에서 PC를 연결하고 사진을 선택합니다. 앱에서 읽은 촬영 시각과 위치를 확인한 뒤 전송합니다.
4. PC 대기함에서 받은 항목을 확인하고 필요한 관찰 기록으로 등록합니다.

개발 환경 구성과 실행 파일 빌드는 [개발자 README](../README.md)를 참고하세요.
