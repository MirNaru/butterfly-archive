# 개발 계획

이 문서는 합의한 개발 범위, 개발 순서와 착수 준비를 정리합니다. 설계 기준일은 2026년 10월 23일입니다.

## 현재 상태와 문서 역할

현재는 연결 확인에 더해 종 수동 등록·목록, 조사와 여러 종별 기록의 등록·목록·상세 조회, 간단한 장소·날짜·종명 검색, 조사 표와 하단 지도·표 탭을 구현했습니다. 네이버 지도·주소 선택과 기상청 ASOS 조회·저장을 추가했습니다. 기상은 한 번 저장하고 자동 갱신하지 않습니다. 조사·종별 기록 수정, 상세 필터, 종별 기본 표와 선택 열, 성충 출현 참고 기간 기반 탐사 검색을 구현했습니다. 삭제·복구, 엑셀 반입, 사진, 출현 도표와 소장 관리 기능은 아직 없습니다.

- [원래 개발 계획서](../DEVELOPMENT%20PROPOSAL.md): 사용자가 작성한 배경과 장기 목표입니다. 원문은 보존합니다.
- [데이터 구조](data-model.md): 확정된 정보의 의미, 관계와 입력 규칙입니다.
- [화면과 완료 기준](requirements.md): 사용자 흐름, 시각화와 기능별 검증 기준입니다.
- [미구현 및 확인 사항](improvement.md): 구현 상태와 아직 결정하지 않은 내용을 관리합니다.

확정된 설계는 구현 완료를 뜻하지 않습니다. 실제 DB 테이블명, API 요청 형식, 마이그레이션 방법은 구현 계획에서 구체화합니다.

## 목표와 우선순위

2026년 10월 31일까지 개인 기록을 등록하고 검색하며 사용할 수 있는 1차 버전을 목표로 합니다. 데이터 정확성, 보존과 복원 가능성을 우선합니다.

1차 범위는 조사와 종별 기록의 등록·조회·수정·삭제, 종 정보, 지도, 엑셀형 표, 검색·필터, 사진·태그, 최소 소장 정보 관리, 과거 기상 연결과 백업·복원입니다. 출현 도표는 참고 기간과 실제 관찰점을 기반으로 구성하며, 상자 수염 통계는 집계 규칙과 자료 조건을 확정한 뒤 적용합니다.

후속 범위는 외부 자료 수집·검증 자동화, 논문 업데이트, 출현 예측, 모바일 원격 접속입니다. 국내 미기록종과 신종은 서로 다른 개념으로 다룹니다. 전체 도감 콘텐츠를 새로 조사하여 채우는 일도 초기 기록 기능과 구분합니다.

지도와 기상 등 외부 서비스는 비용이 발생하지 않아야 합니다. 무료 한도 초과를 알리는 알림만으로는 이 조건을 충족하지 않습니다. 과금 방지를 확인할 수 없는 서비스는 활성화하지 않고 대안을 사용자와 결정합니다.

## 현재 기술 구조와 예정 데이터 흐름

현재는 React + TypeScript + Vite, Python + FastAPI, SQLite이며 로컬 Windows PC에서 실행합니다. 브라우저는 `/api` 요청을 Vite 개발 프록시를 통해 FastAPI로 전달합니다. DB 접근은 백엔드가 담당합니다.

예정 흐름은 화면 입력 → API 입력 검증 → SQLite 저장 → 재조회입니다. 사진 원본과 파생 파일은 로컬 파일로, 연결 정보는 DB로 관리합니다. 지도·표는 같은 기록을 조회하는 화면이며 각각 별도 원본을 만들지 않습니다. 구현 시 저장의 일관성, 실패 처리와 복구 절차를 정합니다.

API 키, 개인 기록, 사진, DB, 백업은 Git에 등록하지 않습니다. 외부 서비스에 실제 위치나 사진을 전송하기 전 목적과 범위를 설명하고 승인을 받습니다. 로컬 서버를 외부에 공개하지 않습니다.

일정은 목표이며 완료 보장이 아닙니다. 외부 API 준비는 지도·기상 구현일보다 앞서 진행합니다. 범위 변경이 필요하면 사용자에게 설명하고 결정받습니다. 모의 지도나 모의 기상을 실제 연동 완료로 보고하지 않습니다.

## 첫 구현 작업의 경계

첫 구현은 종 식별 정보, 조사와 종별 기록의 저장·조회, 연결된 최소 등록·상세 화면을 대상으로 합니다. 데이터 의미는 데이터 구조 문서를 따릅니다. 엑셀 전체 반입, 사진 일괄 반입은 별도 단계입니다. 외부 API 연동과 위치 전송은 후속 승인에 따라 구현했습니다.

코드 변경 전에 실제 파일을 다시 확인하고 수정 예정 파일, 변경 이유, 영향, DB 변경·복구 방안, 테스트 방법을 제시합니다. 이번 문서 작성 승인을 코드 구현·개인 자료 일괄 반입·Commit·Push 승인으로 간주하지 않습니다.

## 사용자 준비

기본 기록 기능 개발에는 지도 키나 구매 자료 분류 완료가 필요하지 않습니다.

- 지금: 지도·기상 사용 방법에 따라 기록 등록·조회 흐름을 확인해 주세요. 추가 개발 도구 설치는 없습니다.
- 자료 반입 전: 엑셀 출현 색은 성충 기준으로 확인했습니다. 구매 자료는 나중에 알려주셔도 됩니다.
- 사진 검증 전: 촬영 정보가 남아 있는 원본 사진 몇 장과 대략적인 기록 예시를 준비해 두시면 좋습니다. 외부 업로드는 하지 않습니다.
- 외부 연동: 키 입력과 기상청 활용신청을 완료했습니다. 네이버 대표 계정의 무료 적용·강제 사용 제한을 유지해 주세요. 키는 채팅이나 저장소에 올리지 않습니다.
- 백업 구현 전: 백업 저장 위치를 정하고 복원 방식의 설명을 확인해 주세요.

현재 기상은 ASOS 과거 시간·일자료이며 당시 관측소를 선택합니다. 제공 기간·관측소별 누락으로 조회가 불가능할 수 있으며 자동 보간하지 않습니다.
