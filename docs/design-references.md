# 화면 디자인 참고 자료

이 문서는 사용자가 고른 네 가지 화면의 특징과 향후 디자인 검토 기준을 보존합니다. 화면 구현 명세가 아니며, 실제 변경 전에는 사용자가 구상한 방향을 먼저 확인합니다.

## 1. 사용자 선호와 현재 결정 상태

- 사용자는 약 30개 사례를 살펴본 뒤 아래 네 가지를 깔끔한 화면으로 선택하셨습니다.
- 정보 관리 프로그램은 **메인 색 하나와 서브 색 하나**를 중심으로 구성하는 방향을 선호하십니다.
- 현재 화면에서 항목 간 간격과 정렬이 어색한 부분을 개선하려는 단계입니다.
- 사용자가 추가 시안을 제공하고 흰색과 #fbbc04 계열, 좁은 왼쪽 창과 넓은 작업 영역을 승인하셨습니다. 구체 내용은 아래 현재 적용 기준을 따릅니다. 폰트 교체는 아직 결정하지 않았습니다.
- 이 자료를 근거로 기능을 추가하거나 기존 요구사항을 변경하지 않습니다.

## 2. 자료의 해석 기준

아래의 시각적 특징은 사용자가 제공한 네 장의 캡처를 기준으로 관찰했습니다. 원본 링크도 함께 보존합니다. 첫 번째와 세 번째는 원본 페이지의 설명도 확인했으며, 두 번째와 네 번째는 페이지 본문을 가져오지 못했으므로 캡처에서 확인되는 내용만 정리했습니다.

색 이름은 화면에서 보이는 계열을 설명합니다. 정확한 색상 코드나 간격 수치를 측정한 결과가 아닙니다. 축소된 소개 이미지이므로 실제 제품의 배율·글자 크기·사용성을 검증한 자료로 취급하지 않습니다.

## 3. 사례별 특징

### 1. B2B Supply Chain SaaS

[원본: B2B Supply Chain SaaS used by shippers and exporters](https://dribbble.com/shots/25816817-B2B-Supply-Chain-SaaS-used-by-shippers-and-exporters)

**전체 인상**

차가운 밝은 회색 바탕과 흰색 카드 위에 파란색을 강조합니다. 노란색은 일부 차트·상태에 보조적으로 쓰입니다. 여러 정보를 한 화면에 배치하지만 카드 경계와 여백으로 묶음을 구분합니다.

**구성과 간격**

- 왼쪽에 폭이 좁은 아이콘 메뉴를 두고 본문 공간을 넓게 확보합니다.
- 상단에는 제목과 작은 도구 버튼, 그 아래에는 가로로 긴 주요 알림이 있습니다.
- 본문은 지도, 수치, 상태 목록, 차트, 표를 크기가 다른 카드로 나눕니다.
- 카드의 시작선·끝선과 카드 사이 간격이 규칙적으로 맞습니다.
- 카드 내부는 제목, 주요 수치, 보조 설명 순으로 글자 크기와 명도를 다르게 둡니다.
- 강한 테두리보다 배경 밝기 차이와 둥근 모서리로 영역을 구분합니다.

**나비 아카이브에 참고할 부분 — 검토 중**

지도와 기록 요약을 함께 보여줄 때 정보의 묶음을 분명하게 나누는 방식이 유용합니다. 큰 숫자·짧은 설명의 구분은 기록 수나 검색 결과 수에도 참고할 수 있습니다. 다만 카드와 통계를 많이 배치하는 구성 자체를 도입하겠다는 뜻은 아닙니다. 좁은 아이콘 메뉴도 현재의 왼쪽 검색·정보창을 대체하는 확정안이 아닙니다.

### 2. Property Listings UI

[원본: Property Listings UI — Real Estate CRM](https://dribbble.com/shots/27716388-Property-Listings-UI-Real-Estate-CRM)

**전체 인상**

따뜻한 밝은 회색 바탕, 흰색 카드, 짙은 글자와 녹색 강조가 중심입니다. 사진이 넓은 면적을 차지해도 주변 장식이 적어 내용이 먼저 보입니다. 주의가 필요한 항목에는 주황색이 제한적으로 쓰입니다.

**구성과 간격**

- 상단 가로 메뉴와 검색 영역을 한 줄로 정돈합니다.
- 본문 제목 아래에는 요약 수치, 그 아래에는 검색 조건을 작은 둥근 버튼으로 나열합니다.
- 보기 전환과 추가 버튼은 같은 높이의 오른쪽 영역에 모여 있습니다.
- 목록은 같은 너비의 카드 세 열로 구성하며 사진 높이와 카드 내부 정렬을 통일합니다.
- 카드에는 사진, 이름과 핵심 수치, 보조 속성, 하단 상태 정보가 순서대로 배치됩니다.
- 선택한 조건은 채운 배경으로 구분하고 나머지는 밝고 가볍게 표시합니다.
- 구분선과 작은 점을 활용해 보조 정보를 과도하게 강조하지 않습니다.

**나비 아카이브에 참고할 부분 — 검토 중**

검색 조건을 짧게 표시하는 방식, 보기 전환과 주요 동작 버튼의 정렬, 반복되는 정보의 일정한 간격을 참고할 수 있습니다. 향후 사진 목록에도 참고할 수 있지만, 현재 표 기본 화면을 사진 카드로 바꾸는 결정은 아닙니다.

### 3. Safetec Tracking Dashboard

[원본: Safetec — Advanced Security Tracking Dashboard](https://dribbble.com/shots/27550764-Safetec-Advanced-Security-Tracking-Dashboard)

**전체 인상**

흰색과 아주 밝은 회색을 넓게 쓰고 보라색 계열로 선택 메뉴와 주요 버튼을 강조합니다. 파랑·주황·빨강·초록은 기능 아이콘이나 상태에 추가로 쓰입니다. 색이 두 개만 있는 화면은 아니지만, 화면 구조와 선택 상태를 나타내는 강조는 비교적 일관됩니다.

**구성과 간격**

- 왼쪽 메뉴와 오른쪽 본문 사이에 분명한 경계가 있습니다.
- 왼쪽 메뉴는 아이콘과 글자를 함께 사용하며 하위 메뉴를 들여쓰기로 구분합니다.
- 선택 메뉴는 연한 강조색 바탕과 진한 글자로 표시합니다.
- 본문 상단의 주요 동작들은 같은 높이에 정렬하고, 아래에는 별도 정보 영역을 둡니다.
- 지도와 표를 같은 카드 안에 좌우로 배치해 위치와 기록의 관계를 보여줍니다.
- 표는 옅은 헤더 배경, 가는 행 구분선, 일정한 행 높이를 사용합니다.
- 상태는 작은 둥근 배지로 표시하며 지도 위 정보창은 흰색 바탕에 짧은 요약을 담습니다.

**나비 아카이브에 참고할 부분 — 검토 중**

왼쪽 검색·정보창의 제목과 하위 항목 계층, 표의 행 간격, 선택 상태와 배지의 표현을 참고할 수 있습니다. 지도와 표를 한 화면에 나란히 두는 구성은 관찰 대상일 뿐이며, 현재 하단 지도·표 전환 요구사항을 변경하지 않습니다. 상단의 큰 동작 영역도 현재 줄여 둔 제목 영역을 다시 확대하는 근거로 사용하지 않습니다.

### 4. California Paramedic Foundation Dashboard

[원본: California Paramedic Foundation — Disorder Event Dashboard](https://dribbble.com/shots/26547040-California-Paramedic-Foundation-Disorder-Event-Dashboard)

**전체 인상**

흰색·회색 화면에 파란색을 중심으로 사용합니다. 지도·집계·표 같은 많은 정보를 낮은 색 대비로 정리하고, 선택된 상세 내용에 시선을 모읍니다.

**구성과 간격**

- 기본 화면 위에 오른쪽 상세 패널이 겹쳐 열리고, 뒤의 화면은 어두워지지만 내용은 보입니다.
- 상세 패널은 제목, 요약, 필터, 시각화, 표, 하단 동작 영역 순으로 구성됩니다.
- 제목과 닫기 버튼, 필터들의 높이, 표의 열 시작선이 정돈되어 있습니다.
- 표에서는 반복되는 보조 정보의 강조를 줄이고 얇은 구분선으로 행을 구분합니다.
- 하단의 동작 버튼과 페이지 이동 도구를 본문 정보와 구분합니다.
- 작은 격자에 같은 색의 명도 차이를 적용해 시간에 따른 빈도를 표현합니다.

**나비 아카이브에 참고할 부분 — 검토 중**

뒤 화면이 보이는 어두운 배경과 전면 창의 대비, 제목·본문·하단 버튼의 구분을 현재 중앙 조사 입력창에 참고할 수 있습니다. 오른쪽 패널 배치를 그대로 도입하지는 않습니다. 시간 격자는 빈도 표현 사례이며, 사용자가 요청한 가로 출현 기간 및 상자 수염 그림을 대체하는 안이 아닙니다.

## 5. 공통적으로 추출한 디자인 원칙 — 적용 후보

1. **색보다 정렬과 간격으로 구조를 만듭니다.** 바탕은 흰색·회색 계열로 두고 제목, 표, 필터의 시작선을 맞춥니다.
2. **강조색의 용도를 고정합니다.** 메인 색은 주요 동작과 선택 상태, 서브 색은 정해진 보조 목적에 사용하는 방향을 검토합니다. 같은 의미에 서로 다른 색을 붙이지 않습니다.
3. **상태색은 별도 의미를 가집니다.** 오류·주의·성공은 글자나 아이콘과 함께 구분합니다. 메인·서브 색 선호를 이유로 모든 상태를 두 색으로만 표현한다고 확정하지 않습니다.
4. **글자의 역할을 나눕니다.** 제목·핵심 값·본문·보조 설명의 크기와 명도를 일정하게 둡니다. 작은 회색 설명을 과도하게 늘리지 않습니다.
5. **같은 요소는 같은 크기를 사용합니다.** 버튼과 입력칸의 높이, 모서리, 좌우 여백, 표 행 높이를 화면 전체에서 맞추는 방향을 검토합니다.
6. **관련 항목끼리는 가깝게, 다른 묶음은 충분히 떨어뜨립니다.** 모든 간격을 똑같이 만드는 것이 아니라 정보 관계가 보이도록 단계를 둡니다.
7. **기본 화면에는 자주 보는 정보를 우선합니다.** 부가 내용은 기존 상세·선택 표시 원칙과 함께 검토하며, 사용자가 요구한 입력 항목을 임의로 숨기지 않습니다.

## 6. 사용자 구상 후 결정할 사항

- 메인 색과 서브 색의 계열 및 각각의 역할.
- 차가운 회색과 따뜻한 회색 중 전체 바탕의 방향.
- 구분선 중심과 카드 배경 중심 중 선호하는 영역 구분 방식.
- 기록을 촘촘하게 보여주는 정도와 여백의 균형.
- 왼쪽 정보창, 표, 조사 등록창 각각에서 선호하는 참고 사례와 요소.
- 모서리의 둥근 정도, 그림자 강도, 선택 상태의 표시 방식.

이 문서를 읽은 다음 작업자는 위 항목을 이미 결정된 사양으로 취급하지 말고 사용자가 추가로 제시한 구상을 먼저 확인해야 합니다. 간격·색상 수치는 실제 한국어 데이터와 화면 크기에서 검증한 뒤 정합니다.

## 7. 기존에 확정한 화면 요구사항

- 하단에는 지도 / 표 / 나비 도감 / 자료 수집 탭을 둡니다.
- 지도 화면의 정보창은 왼쪽에 둡니다.
- 새 조사 등록은 지도·표 모두 기존 화면 위의 중앙 창에서 진행하고 배경을 약간 어둡게 합니다.
- 표 기본 표시열은 국명, 학명, 장소, 시간, 기상입니다.
- 기존 엑셀 출현 기간은 어른벌레 기준이며 축약 표기는 연간 36구간을 사용합니다. 현재 한살이 도표는 네 단계와 일 단위 경계를 지원하고 관찰점·20사례 이상 상자 수염·사례 안내를 구현했습니다.

참고 화면의 메뉴 위치·사진 카드·오른쪽 상세 패널·통계 표현이 위 요구사항을 자동으로 변경하지 않습니다.


## 8. 사용자 시안에 따른 현재 적용 기준

사용자의 슬라이드 캡처는 배치와 분위기를 참고하며 캡처의 불규칙한 간격과 글자색을 그대로 옮기지 않습니다. 보이지 않는 기존 기능을 삭제하지 않습니다.

- PC 화면의 왼쪽 창은 240px로 고정합니다. 브라우저를 늘려도 너비가 변하지 않습니다. 620px 이하에서는 위아래 배치로 전환합니다.
- 화면 바깥 여백과 패널 사이 간격, 왼쪽 패널 안쪽 여백은 모두 12px입니다. 오른쪽 일반 본문 안쪽 여백은 20px입니다. 지도 화면의 상하 여백은 10px이며 좌우는 왼쪽 창 내부와 같은 12px입니다. 같은 역할의 간격을 통일하며 모든 종류의 간격을 같은 숫자로 만들지는 않습니다.
- 흰색 바탕에 #fbbc04, 연한 노란색과 중립적인 회색을 사용합니다. 원형 아이콘의 바탕은 정확히 #fbbc04입니다. 선택·초점 상태는 외곽선으로 구분합니다. 여섯 버튼은 28px 정원, 내부 SVG는 21px로 고정합니다. 본문은 짙은 회색이며 기존 설치 글꼴을 유지합니다.

지도 상단의 핀 버튼과 지도 종류 묶음 사이 간격은 지도와 바깥 패널의 좌우 간격인 12px입니다. 일반지도·위성지도는 서로 붙인 이전 형태를 유지합니다. 외부 연결 안내는 지도 아래 저장 안내 영역에 표시합니다. 버튼은 약 29px 높이로 줄이며, 하단 안내의 가로 구분선을 제거하고 글자를 기존 11px에서 1pt 줄입니다. 하단 세로 여백은 10px에서 5px로 줄이고 지도는 남는 높이를 채웁니다. 실제 지도 SDK 추가 호출 없이 차단된 시험 화면에서 간격·크기를 측정했습니다.


나비 기본 정보 탭은 왼쪽에 등록·국명/학명 검색·그림 조건, 오른쪽에 표만 배치합니다. 한살이 기간 셀은 월 공통 축에 알·애벌레·번데기·어른벌레 네 행을 둡니다. 차분한 파랑 #6b8ca8, 초록 #718b67, 갈색 #b08c5e, 보라 #917ba3를 사용합니다. 도감은 옅은 막대, 관찰은 점과 상자·중앙선·수염으로 구분합니다. 단계 이름과 범례도 제공합니다. 마우스를 올리면 요약 안내, 클릭하면 출처·판본·전체 관찰 사례를 중앙 창에서 확인합니다. 표 자체는 가로 스크롤을 사용합니다.

현재 하단 탭 표기는 지도 / 표 / 나비 도감 / 자료 수집입니다. 도감 상단 제목도 나비 도감으로 표시합니다. 지도와 같은 18px·700 굵기, 제목 왼쪽 8px와 아래 방향 2px 보정, 상단 여백 10px·좌우 12px, 제목 영역 최소 높이 29px·표까지 간격 10px를 적용합니다.

관찰 기록표도 지도·도감과 같은 제목 크기와 상단 간격을 사용합니다. 관찰 기록/조사 목록 선택, 정렬, 방향, 표시 열 선택은 한 줄로 배치합니다. 열 선택 목록은 아래쪽 레이어로 열어 본문을 밀지 않으며 Escape 또는 영역 밖으로 초점 이동 시 닫습니다. 비율 박스는 관찰 기록표 제목 바로 아래, 조작 행 위에 두고 분모가 0이면 빈칸으로 표시합니다. 기존 분모 설명과 표 위 안내 문장은 제거하며 계산 규칙은 유지합니다.

기록 없는 종 참고 행은 클릭 가능한 버튼으로 표시하지 않으며 표 아래 기본 정보를 열지 않습니다. 종 정보 조회·편집은 나비 도감에서 수행합니다. 실제 관찰 기록의 상세 조회와 수정은 유지합니다.

도감은 국명·학명을 한 열에 위아래로 배치합니다. 첫 열 210px, 한살이 기간 440px, 기주식물 120px, 서식지·습성·기타 각 190px, 마지막 동정 포인트 220px로 구성합니다. 기주식물은 목록으로 세로 표시하고 동정 포인트는 사용자 줄바꿈을 유지합니다. 기본 표 최소 너비 1560px와 표 자체의 가로 스크롤을 유지합니다. 기존 기주식물 원문은 바꾸지 않습니다.

도감 표는 패널 안에서 세로로 스크롤하며 표 아래 고정 줄에 항상 보이는 가로 스크롤 바를 둡니다. 표의 가로 위치와 양방향으로 연동하고 창 크기가 바뀌면 범위와 손잡이 너비를 갱신합니다. 드래그·방향키·Home/End·PageUp/PageDown으로 조작합니다. 손잡이 높이는 6px, 트랙은 4px, 전체 영역은 12px, 도감 본문 하단 여백은 4px입니다. 동정 포인트를 포함한 열은 고정하지 않습니다.

도감 표의 외곽선과 둥근 모서리는 스크롤 컨테이너가 아닌 실제 table에 적용합니다. 세로 스크롤 여유 공간은 테두리 밖에 두어 머리글 배경과 행 구분선이 오른쪽 외곽선까지 자연스럽게 이어지도록 합니다.
