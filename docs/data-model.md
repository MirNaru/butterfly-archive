# 데이터 구조

이 문서는 합의된 논리적 데이터 구조입니다. 종 식별 정보·조사·종별 기록과 외부 기상 저장은 스키마 버전 3으로 구현했습니다. 버전 3은 종 탐사 참고자료 테이블을 추가합니다. 나머지 상세 자료 구조는 목표 사양입니다. 원본 값, 정리한 값, 추정값을 구분하며 모르는 값은 0이나 임의 날짜로 바꾸지 않습니다.

## 관계와 소유 범위

- 한 조사에는 여러 종별 기록이 연결됩니다. 한 조사에 여러 종·단계·개별 위치를 기록할 수 있습니다.
- 종별 기록은 확인된 경우 종 정보에 연결합니다. 동정 미확정 관찰도 보존합니다.
- 한 종에는 여러 출현 참고 기간, 분포 자료, 목격 사례, 소장 기록이 연결될 수 있습니다.
- 직접 채집한 소장 기록은 개인 관찰과 연결할 수 있습니다. 구매 자료는 개인 조사를 자동 생성하지 않습니다.
- 사진·태그·기상은 적용 대상과 출처를 명확히 연결합니다. 종의 일반적 생태와 개별 현장 사실을 혼합하지 않습니다.

각 주요 기록에는 내부 식별번호와 생성·수정 시각을 둡니다. 외부 자료에는 출처·원문·검토 상태를 보존합니다. 엑셀 번호나 종명을 영구 식별번호로 사용하지 않습니다.

## 종 정보

| 항목 | 규칙 |
| --- | --- |
| 국명·학명 | 엑셀 원본을 보존합니다. 최신 명칭으로 검증되었다고 가정하지 않습니다. |
| 과·아과 | 기준 시트의 값을 초기 참고 자료로 사용합니다. |
| 생태적 특징 | 일반적인 활동 시간대, 행동, 서식 환경을 기록합니다. 조사 시작·종료 시각의 대체 필드가 아니라 종의 특성입니다. |
| 기주식물 | 여러 식물과 연결할 수 있습니다. 원문도 유지합니다. |

| 비고·출처·검토 상태 | 원본 문구를 보존합니다. 보호 관련 메모를 최신 법적 상태로 단정하지 않습니다. |

동의어·학명 변경을 원본 종명에 무단 덮어쓰지 않습니다. 종과 기주식물 관계의 정확성을 임의로 확정하지 않습니다.

## 출현 참고 기간과 분포

문자 요약과 기존 자료 반입은 연간 36개 구간을 사용합니다. 각 월의 1~10일, 11~20일, 21일~월말이며 2월도 포함합니다. 윤년의 2월 마지막 구간은 9일입니다.

기간에는 종, 발육 단계 또는 단계 미확인, 시작·끝 구간, 출처를 연결합니다. 서로 떨어진 기간과 연말을 넘어 이어지는 기간을 표현할 수 있어야 합니다. 사용자가 제공한 기존 엑셀의 출현 기간은 성충 기준으로 확정했습니다. 네이처링 목격 사례를 주로 취합한 사용자 정리 자료이며 원본 사례별 출처를 검증한 상태는 아닙니다. 알·유충·번데기의 출현 기간으로 복사하지 않습니다.

색이 없는 칸은 원본의 출현 표시가 없는 상태이며, 확실한 부재로 간주하지 않습니다. 실제 관찰 날짜는 36구간으로 손실 압축하지 않고 일 단위로 보존합니다.

분포 지역은 종의 참고 분포이며 개인 관찰 좌표가 아닙니다. 지역 원문을 보존하고 정규화한 행정구역은 별도로 연결합니다. 분포가 있다는 이유로 도시 중심점에 관찰 핀을 생성하지 않습니다.

## 참고 목격 사례

종, 확인된 날짜와 날짜 정확도, 장소, 증거·원본 URL, 출처, 검토 상태를 관리합니다. 연도만 확인되면 연도만 저장하고 월·일을 만들어 넣지 않습니다.

미접 메모의 괄호 안 연도는 확실한 목격 사례가 있는 연도이며 마지막 목격 연도라고 단정하지 않습니다. 여러 연도·지역의 사례를 연결할 수 있습니다. 사용자 제공 설명은 원문이 검증된 외부 사실과 구분합니다. 외부 목격을 개인 관찰이나 국내 정착의 증거로 자동 확정하지 않습니다.

## 조사

| 항목 | 필수 여부와 규칙 |
| --- | --- |
| 조사 날짜 | 필수입니다. |
| 장소명 또는 위치 | 둘 중 하나 이상 필요합니다. |
| 대표 좌표·주소·행정구역 | 선택입니다. 정확한 위치를 모르는 기록도 저장합니다. |
| 조사 목적 | 일반 관찰, 특정 종 탐색, 기주식물 확인, 신규 지역 조사 등을 기록합니다. |
| 공통 환경·메모 | 선택입니다. |
| 조사 시작·종료 시각 | 두지 않습니다. |

종별 기록은 조사 날짜·위치를 기본값으로 사용하되 더 구체적인 개별 값을 지정할 수 있습니다. 상속과 개별 지정의 구분을 보존합니다. 조사 수정 시 개별 날짜·위치를 비운 기록만 변경한 조사 값을 따르며 개별 지정 값은 유지합니다.

현재 구현에서는 개별 날짜를 비우면 조회 시 조사 날짜를 사용합니다. 개별 위치가 모두 비어 있으면 조사 위치를 사용하고, 개별 장소명 또는 좌표가 있으면 그 개별 위치만 사용합니다. 장소명만 바꾼 기록에 조사 좌표를 잘못 붙이지 않습니다. 좌표 입력은 WGS84의 위도·경도 별도 필드이며 두 값이 함께 필요합니다. 관찰 시각은 한국 현지 시각으로 입력합니다. 수정은 기존 조사·종별 기록 ID와 생성 시각을 보존하고 조사 수정 시각을 갱신합니다. 요청의 expected_updated_at이 현재 수정 시각과 다르면 409로 거부합니다. 기존 종별 기록의 누락·중복·다른 조사 ID 포함을 거부하며 새 기록 추가는 허용합니다. DB 구조 변경은 없습니다.

위치에는 입력 방법과 정확도를 보존합니다. GPS, 지도 지정, 대략적 위치를 구분합니다. 좌표계·필드 순서는 구현 시 명시하고 위도·경도를 혼동하지 않도록 검증합니다.

## 소장 정보

종, 성별, 수량 또는 미상, 취득 경로, 선택적 취득 날짜, 연결된 개인 관찰, 사진·메모와 원본 출처를 관리합니다. 취득 경로는 직접 채집, 구매, 기타, 미확인입니다.

기존 엑셀 암수 체크는 소지 여부만 뜻합니다. 체크를 수량 1 또는 직접 채집으로 변환하지 않습니다. 취득 경로는 확인 전까지 미확인입니다. 같은 종의 구매와 직접 채집 자료가 함께 존재할 수 있습니다. 구매 장소·취득 날짜는 야생 관찰 장소·날짜가 아닙니다.

관찰 종 수, 직접 채집 수량, 소장 종 수를 별도 집계합니다. 수량 미상은 알려진 수량 합계와 분리하여 표시합니다.

## 사진, 기상, 태그

사진 원본과 썸네일은 별개로 관리합니다. 원본의 임의 삭제·변환·이름 변경을 하지 않습니다. 촬영 시각은 관찰 시각 입력 후보로 제시하며 사용자가 확정한 관찰 시각과 별도 보존합니다. 여러 사진의 시각이 다르거나 촬영 정보가 없으면 임의로 시간을 선택하지 않습니다.

기상은 현장값과 외부 관측값을 구분합니다. 대상 날짜·시각 또는 집계 기간, 관측소, 출처, 조회 시각, 단위, 누락 상태를 보존합니다. 외부값이 현장값을 덮어쓰지 않습니다. 시각 미상 기록의 일별 요약은 시간별 관측값과 명확히 구분합니다. 관측소 값은 현장의 정확한 날씨라고 단정하지 않습니다.

태그는 환경·행동·특이사항을 보완합니다. 날짜, 개체 수, 발육 단계 같은 구조화된 항목을 태그로 대체하지 않습니다.

## 엑셀 반입과 원본 추적

기준은 제공된 엑셀의 나비 아카이브 시트입니다. 종 정보, 출현 참고 자료, 소지 표시를 분리합니다. 기주식물 아카이브는 연결 참고 자료이며 중복 후보는 자동 병합하지 않습니다. Abandoned나비목록은 반입 대상에서 제외합니다.

원본 파일 식별 정보, 시트·행·열과 원문을 개인 데이터 영역에서 추적할 수 있도록 설계합니다. 소지 목록과 실제 개인 값은 설계 문서나 Git 저장소에 복사하지 않습니다. 반입 전에 건수·중복·빈 값·색 의미·변환 결과 미리보기를 확인하고 백업 및 승인 후 반영합니다.

기존 가중치 점수와 계산식은 참고 자료로 보존하되 기본 추천·예측에는 사용하지 않습니다. 분포 상수 324와 162, 과거 연도 경계 규칙의 근거는 확인되지 않았습니다.

## 보존과 DB 변경

DB를 삭제하거나 초기화하여 변경 오류를 해결하지 않습니다. 스키마 변경 전 영향, 기존 자료의 이동 방식, 백업과 복구 방법을 제시합니다. DB와 사진 원본을 함께 백업하는 방향이며 구체 형식은 검토 중입니다. 기록 삭제와 사진 파일 삭제는 분리하고 사진 원본은 자동 삭제하지 않습니다.

## 구현된 스키마 버전 2

- species: 고유 번호, 국명, 선택적 학명, 생성 시각입니다. 국명 중복은 자동 병합하지 않고 충돌로 응답합니다.
- surveys: 날짜, 장소명, 좌표와 입력 방식, 목적, 메모, 생성·수정 시각입니다.
- observations: 조사와 종의 참조, 발견 여부, 개별 날짜·시각·위치, 단계·성별·수량·추정 여부·동정 상태·채집 여부·채집 수량·메모입니다.
- 한 조사와 그 기록은 같은 트랜잭션으로 저장합니다. 존재하지 않는 종이나 저장 실패 시 부분 저장하지 않습니다.
- 미발견 기록은 대상 종을 요구하고 관찰된 단계·성별·수량·채집·동정 결과를 허용하지 않습니다. 관찰 수량이 알려졌다면 채집 수량이 이를 넘지 않도록 검증합니다.
- 가상환경의 기존 의존성만 사용했습니다. 원본 엑셀에서는 국명·학명·기주식물만 반입했으며 소장 자료는 반입하지 않았습니다.

앱 시작 시 user_version이 0이면 기록·연동 테이블을 생성하며, 1이면 기존 기록을 유지하고 연동 테이블만 추가합니다. 내용이 있는 기존 파일은 먼저 SQLite backup API로 같은 폴더에 `.before-v2-날짜.bak` 백업을 만듭니다. 스키마 추가와 버전 기록은 트랜잭션 안에서 수행하며 실패 시 되돌립니다. 같은 이름의 기존 테이블이나 지원하지 않는 버전이면 실행을 중단하고 기존 자료를 보존합니다. 버전 2에서는 반복 변경하지 않습니다.


- api_usage: 서비스·한국 날짜별 호출 시도 수입니다. 호출 전 트랜잭션으로 예약하며 실패도 누적합니다.
- weather_stations: 조회 대상 시점별 관측소 목록과 수집 시각입니다. 현재 관측소 위치를 과거 기록에 일괄 적용하지 않습니다.
- weather_samples: 관측소 번호·시간/일자료 구분·대상 시점·원본 수치 문자열·해석 값·단위·출처·조회 시각입니다. 새로 조회한 값은 별도 행으로 보존합니다.
- weather_links: 조사 또는 종별 기록 중 하나와 기상자료를 연결합니다. 연결 당시 날짜·시각·장소·좌표, 관측소 정보와 거리를 보존합니다. 기록 조건이 바뀌면 이전 자료임을 표시합니다.
- 시간 미상은 일자료, 시간 지정은 해당 시간 직전 정시의 ASOS 시간자료입니다. 저장값 자동 갱신은 없습니다. 같은 관측소·자료 종류·대상 시점의 저장값을 재사용합니다. 명시적 재조회는 해당 기록만 새 자료와 연결하며 실패 시 기존 연결을 유지합니다.
- 음수 기온은 유효 범위 내에서 보존합니다. 강수량 등의 음수 결측값은 null로 표시하고 원본 문자열도 보존합니다. 시간자료의 강수량은 해당 시각까지의 일 누적량입니다.
- 좌표는 WGS84 위도·경도 필드로 저장합니다. 입력 방식에는 `map`과 `address`를 추가했으며 두 방식 모두 좌표 쌍을 요구합니다.


## 구현된 종 탐사 참고자료 · 버전 3

- species_references: species_id를 기준으로 검증된 JSON 참고자료와 수정 시각을 저장합니다. 기존 species·surveys·observations와 기상 연결은 변경하지 않습니다.
- 성충 출현 기간은 시작·끝 구간 번호 1~36으로 보존합니다. 겹치거나 인접한 구간은 계산 시 합치며, 시작이 끝보다 뒤인 구간은 연말을 넘어갑니다. 기준일부터 현재 연결된 구간의 마지막 날짜까지의 차이를 남은 일수로 표시합니다. 마지막 날은 0일, 윤년 2월은 29일 기준입니다. 전 구간이 채워지면 연중으로 표시하고 종료일을 만들지 않습니다. 다음 구간 존재 여부는 해당 연도에 남아 있는 참고 구간을 뜻합니다.
- 분포 원문 지역 목록, 북한에만 분포하는지, 미접 여부, 확인된 목격 연도 목록과 출처를 저장합니다. 미접이면서 연도 목록이 있고 모든 연도가 2010 미만일 때만 미갱신 미접으로 분류합니다. 연도 미상은 이 분류에 포함하지 않습니다.
- 과거 채집 여부는 미확인·채집한 적 있음·채집한 적 없음과 확인 근거로 관리합니다. 앱에 해당 종의 실제 채집 기록이 있으면 이를 우선합니다. 관찰 기록 부재나 구매 소장은 미채집 확정·직접 채집으로 변환하지 않습니다.
- 보호종 여부는 미확인·해당·아님과 출처·확인일입니다. 별도의 채집 가능 판단은 사용자 확인값, 대상 지역, 적용 시작·종료일, 근거를 저장합니다. 자동 법적 판단 기능이 아닙니다. 목표 지역과 정확히 일치하고 기간 내일 때만 해당 판단을 사용합니다.
- 참고자료 수정은 expected_updated_at으로 동시 편집 충돌을 거부합니다. 출처가 필요한 값은 근거 없이는 저장하지 않습니다.
- 버전 0·1·2에서 3으로 이전할 때 기존 DB를 .before-v3-날짜.bak로 먼저 백업합니다. 필요한 테이블만 같은 트랜잭션으로 추가하며 실패하면 DB 버전과 테이블 변경을 롤백합니다. 3이면 반복 변경하지 않습니다.

## 기록 검색과 기상 요약

종별 표는 관찰 한 건당 한 행이며 기본 열은 국명·학명·장소·시간·기상입니다. 실제 적용 날짜·위치를 검색하며 입력값과 상속 상태는 변경하지 않습니다. 종별 기상 열은 해당 종별 기록에 명시적으로 연결한 저장 자료만 표시합니다. 조사 기상을 개별 기록 기상으로 자동 복사하지 않습니다. GET /api/record-weather는 로컬 저장값과 현재 조건 차이만 읽으며 외부 API를 호출하지 않습니다.

## 구현된 기주식물 저장

종 참고자료 JSON에 host_plants(원문 문자열, 최대 5000자)와 host_plants_source(출처, 최대 2000자)를 추가합니다. 기주식물 값이 있으면 출처가 필요합니다. 기존 JSON에 두 필드가 없으면 빈 문자열로 응답하며 테이블 구조와 DB 버전 3은 유지합니다. 종 목록 응답의 host_plants는 같은 참고자료에서 읽는 값이며 별도 복제 저장하지 않습니다.

나비.xlsx의 나비 아카이브 시트 F열 국명, G열 학명, AR열 기주식물에서 282종을 반입했습니다. 기주식물 문자열은 양끝 공백만 제거하고 구분 기호와 원문 표현을 유지합니다. 기주식물 219종, 미등록 63종이며 원본 셀 출처를 함께 저장합니다. 다른 시트·소지 표시·관찰·출현·분포는 이번 반입 대상이 아닙니다.

## 구현된 분류와 기본 표시 순서

종 참고자료 JSON에 family, subfamily, display_order(1 이상 정수 또는 미지정), taxonomy_source를 저장합니다. 분류나 표시 순서가 있으면 출처가 필요합니다. 기존 DB 버전 3과 테이블 구조는 유지하며 없는 필드는 빈 문자열 또는 미지정으로 응답합니다. 편집 화면은 분류·출처를 읽기 전용으로 표시하고 다른 참고자료를 저장할 때 함께 보존합니다.

표시 순서는 사용자 지정 과 순서(호랑나비과, 네발나비과, 흰나비과, 팔랑나비과, 부전나비과), 각 과에서 엑셀 아과 첫 등장 순서, 해당 아과 안의 원본 행 순서로 계산한 순번입니다. 원본 행 위치는 출처에 남기며 원본 엑셀을 수정하지 않습니다. 검은눈그물나비와 푸른줄까마귀왕나비는 각각 뱀눈나비아과와 왕나비아과 끝으로 이동합니다. 아과 소속 확인 자료는 아래와 같으며 아과 내 정확한 계통 분기 순서를 주장하지 않습니다.

- [검은눈그물나비 국내 보고 논문](https://db.koreascholar.com/Article/Detail/436468)
- [푸른줄까마귀왕나비 국내 보고 논문](https://db.koreascholar.com/article/Detail/414540)

282종에 분류와 표시 순서를 추가했으며 나머지 JSON 값, 종 식별번호, 이름, 기주식물, 조사·관찰·기상 자료는 전후 대조로 보존을 확인했습니다. 표시 순서가 없는 종은 분류 목록 뒤에 내부 식별번호 순서로 표시합니다. 사용자 지정 관찰 표의 날짜·국명·수량 정렬과 탐사 결과의 남은 일수 정렬은 별도 기능입니다.
