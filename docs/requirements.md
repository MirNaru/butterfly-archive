# 화면 구성과 완료 기준

아래 내용은 확정된 목표 사양입니다. 현재는 종 수동 등록, 탐사·종별 기록 등록과 목록·상세 조회, 통합 검색·필터, 관찰 기록표와 하단 지도·기록·나비 도감·자료 수집 탭을 구현했습니다. 환경 태그와 한살이 도표도 구현했습니다. 네이버 지도·주소 선택과 ASOS 기상 조회·저장도 구현했습니다. 탐사·종별 기록 수정과 사진·소장 관리도 구현했습니다. 탐사·관찰의 휴지통 삭제·복구도 구현했으며 사용자용 백업·복원은 보류했습니다. 데이터 의미는 [데이터 구조](data-model.md), 구현 상태와 미정 사항은 [미구현 및 확인 사항](improvement.md)을 따릅니다.

## 화면 배치와 탐색

화면의 활동 단위 명칭은 탐사입니다. 기존 데이터 호환을 위해 코드의 Survey·survey_id·surveys와 API /surveys는 그대로 사용합니다. 개인 입력 원문이나 기존 출처 메모는 용어 변경 대상으로 삼지 않습니다.

왼쪽 제목·검색·등록 버튼·하단 탭은 고정하고 노란 정보 박스만 세로로 스크롤합니다. 스크롤바는 노란 박스 밖의 흰 오른쪽 여백에 배치합니다. Chromium 계열의 세로 스크롤바는 3px로 도감 가로 손잡이 6px의 절반이며, 기본색 #fbbc04를 조정한 #d8a514 손잡이와 #fff8e1 트랙을 사용합니다. 다른 브라우저는 지원 가능한 얇은 스크롤바로 표시합니다. 왼쪽 패널의 240px 고정 폭과 버튼 간격은 유지합니다.

왼쪽 패널 하단에 지도 / 기록 / 나비 도감 / 자료 수집 탭을 둡니다. 지도와 기록은 같은 데이터베이스의 기록을 다른 방식으로 보여줍니다. 실제 Excel 앱이나 원본 엑셀을 열어 동기화하는 기능은 아닙니다.

- 지도 탭: 왼쪽 정보창, 오른쪽 넓은 지도입니다. 정보창에 검색·필터·목록·선택한 기록 상세를 표시합니다. 탐사 등록·수정은 중앙 창에서 진행하며 정보창 접기는 후속 범위입니다.
- 기록 탭: 넓은 엑셀형 표입니다. 관찰 기록 / 탐사 목록 / 소장 목록을 선택합니다. 관찰 기록표는 국명 열 고정, 정렬·검색·필터를 지원합니다. 종 정보는 나비 도감 탭에서 조회·편집합니다.
- 탭 전환 시 적용 가능한 검색 조건과 선택한 기록을 유지합니다. 서로 다른 목록으로 전환할 때 지원하지 않는 조건을 조용히 적용하지 않습니다.
- 핀 선택 시 왼쪽에 기록을 표시합니다. 표에서 기록 선택 후 지도 전환 시 해당 위치를 보여줍니다. 좌표 미지정 기록은 표·목록에 남기고 지도 이동 불가를 안내합니다.
- 동일 위치의 여러 기록은 선택 목록으로 확인합니다. 마커 숨김·필터 변경·지도 이동으로 핀이 중복되지 않아야 합니다.
- 필터에서 잠시 제외된 위치 핀은 숨김 보관 상한 8,000개 안에서 재사용합니다. 변경 없는 핀은 지도 연결 명령을 반복하지 않으며, 현재 결과에 새로 들어오거나 빠지는 핀만 연결·분리합니다. 보관 상한 초과 시 오래 사용하지 않은 숨긴 핀부터 정리하고 표시 중인 핀은 유지합니다. 복원된 핀의 클릭 내용·출처 색·직접 관찰 우선순위는 최신 필터 결과와 일치해야 합니다. 직접·간접 관찰을 함께 통합하고 현재 지도와 주변 여유 범위에 필요한 핀을 표시합니다. 직접 관찰이 있는 핀은 위에 표시합니다. 제공된 나비 SVG의 중앙에 전체 탐사 수, 주황 날개에 직접 탐사 수를 표시합니다. 같은 탐사는 통합 안에서 한 번 셉니다. 원호는 간접 출처별 관찰 비율을 표시하며, 소수 출처도 보이도록 최소 폭을 확보합니다. 제목에서 위치 수와 출처별 관찰 건수를 구분합니다. 클릭하면 분리되는 수준으로 확대하고 같은 좌표의 여러 기록은 기존 선택 목록을 사용합니다. 통합은 표시 방식이며 100m·시간·성장 단계에 따른 데이터 중복 판정이나 원본 병합을 수행하지 않습니다.

관찰 행을 더블클릭하거나 국명 버튼에서 Enter를 누르면 중앙 상세창을 열며, 기록 수정도 같은 창에서 진행합니다. 셀 직접 편집, 여러 셀 붙여넣기와 일괄 수정은 별도 범위입니다. 왼쪽 정보창은 PC에서 240px 고정 폭이며 탐사 등록·수정은 중앙 창에 공통 정보와 종별 기록을 나누어 배치합니다.

## 화면별 기능

| 화면 | 기능 |
| --- | --- |
| 기록 목록 | 탐사별 목록과 종별 보기, 새 탐사 등록, 검색·필터 |
| 등록·수정 | 날짜·장소 → 여러 종별 기록 → 사진·생태·태그 → 기상 확인 → 저장 |
| 상세 | 사진, 종·개체·채집 정보, 위치, 기상 출처, 메모와 수정 시각 |
| 종 정보 | 국명·학명, 생태·동정 메모, 기주식물, 출현 도표와 분포 참고 |
| 소장 | 암수 소지 상태, 수량, 취득 경로와 연결된 기록 |
| 설정·휴지통 | 연동 상태, 외부 조회 설정, 삭제 기록 복구. 사용자용 백업·복원은 보류 |

입력 선택 항목은 구역을 나누어 접을 수 있게 합니다. 저장 실패 시 입력 내용이 사라지지 않아야 합니다. 현재 수정 시각 표시와 모든 변경 내역의 이력 보존은 다른 기능이며, 전체 수정 이력 기능은 아직 확정하지 않았습니다.

## 검색과 통계

| 대상 | 조건 |
| --- | --- |
| 관찰 기록 | 종, 실제 관찰 기간, 지역, 단계, 성별, 발견 여부, 채집 여부, 태그, 기온과 그 출처 |
| 종 정보 | 과·아과, 국명·학명, 일반 출현 시기, 기주식물, 분포 지역, 미접 여부 |
| 소장 정보 | 종, 성별, 소지 여부, 취득 경로 |

실제 관찰 날짜와 일반 출현 기간을 혼동하지 않습니다. 현장 기온과 외부 관측 기온은 구분합니다. 지도와 표에 같은 기록 조건을 적용하면 결과 건수가 일치해야 합니다. 구매·외부 목격 자료는 개인 관찰 통계에 자동 포함하지 않습니다.

## 가로형 출현 도표

가로축은 1월부터 12월, 세로축은 알·애벌레·번데기·어른벌레입니다. 단계 미확인 자료를 어른벌레으로 자동 분류하지 않습니다. 문자 요약은 36구간을 사용하지만 실제 관찰점의 날짜는 일 단위로 표시할 수 있어야 합니다.

초기 엑셀의 어른벌레 기간 반입 이후 사용자가 단계별 기간을 보완했습니다. 현재 DB의 사용자 수정값을 기준으로 하며 초기 엑셀로 다시 덮어쓰지 않습니다.

| 표시 | 의미 |
| --- | --- |
| 옅은 가로 막대 | 엑셀·도감의 출현 참고 기간 |
| 작은 점 | 실제 관찰 사례의 날짜 |
| 상자 | 자료 조건이 충족될 때 관찰 날짜의 가운데 50% 구간 |
| 상자 안 선 | 관찰 날짜의 중앙값 |
| 수염 | 명시한 통계 규칙에 따른 범위이며 최초·최종 관찰일과 혼동하지 않게 설명 |

색상만으로 출처를 구별하지 않고 범례·문구를 함께 제공합니다. 기존 엑셀 기간만으로 사분위수나 상자를 생성하지 않습니다. 자료가 적을 때는 참고 막대와 관찰점을 우선 보여줍니다.

지역·연도·단계를 선택하여 비교합니다. 관찰 통계의 기간 선택·사분위수·수염·이상값 판정은 도감과 독립적입니다. 현재는 단계별 연간 관찰 날짜의 분포를 표시하며 도감에서 발생 차수를 자동 분리하거나 확정하지 않습니다. 빈 기간의 연속 출현을 뜻하지 않음을 안내합니다. 여러 발생 차수의 관찰 기반 분리 기준은 후속 검토 사항이며 연말·연초와 윤일은 처리합니다.

사진 장수·채집 개체 수는 관찰 빈도를 자동으로 늘리지 않습니다. 사용자가 검수 후 등록한 단계 지정 관찰 사례를 날짜·장소·출처 단위로 묶고 단계별 20사례부터 선형 보간 사분위수와 1.5 IQR 수염을 표시합니다. 도감 기간 밖 관찰도 동일하게 포함하고 도감 수정·삭제가 통계에 영향을 주지 않습니다. 통계적 이상값은 점으로 보존합니다. 상세 규칙은 data-model.md에 있습니다. 조사 노력·지역 편향 보정과 자동 발생 차수 판정은 후속 범위입니다. 표시는 수집된 날짜의 분포이지 출현 확률·풍부도·실제 개체 수 분포가 아닙니다.

## 도표 상호작용

- 참고 막대에 마우스를 올리면 기간·성장 단계·출처를 보여줍니다.
- 현재 단계별 마우스 안내는 날짜·지역·출처·표본 수를 보여주며 클릭하면 전체 사례와 원본 기록 ID를 엽니다. 개별 점의 시각·개체 수·사진 미리보기와 기록 상세 바로 이동은 후속 범위입니다.
- 상자에는 집계 조건·기록 수·중앙값·범위와 관련 사례를 표시합니다.
- 클릭하면 사례 목록을 중앙 창으로 엽니다. 마우스를 유지해야만 정보를 볼 수 있는 구조로 제한하지 않습니다.
- 종 목록의 표에서도 작은 가로 도표를 제공하여 종 간 시기를 비교할 수 있도록 합니다.

## 기능별 완료 기준

| 기능 | 확인할 결과 |
| --- | --- |
| 등록·수정 | 저장 후 재조회와 서버 재시작 후 값이 유지되고 탐사·종별 기록 관계가 일치합니다. |
| 입력 검증 | 필수 누락, 잘못된 날짜·좌표·수량, 미상 값과 서로 모순되는 입력을 처리합니다. |
| 미발견 | 기록 없음, 기주식물만 확인, 대상 종 미발견을 구분합니다. |
| 삭제 | 합의한 삭제·복구 규칙을 따르고 관련 사진 원본이 자동 삭제되지 않습니다. |
| 지도·표 | 선택 연동, 동일 필터 결과, 좌표 없는 기록, 빈 결과, 중복 핀을 확인합니다. |
| 사진 | 형식·크기 검증, 실패 처리, 원본과 썸네일 구분, 촬영 정보가 없거나 다른 경우를 확인합니다. |
| 기상 | 실제 API와 모의 응답 검증을 구분하고 누락·통신 실패가 기록 저장을 막지 않습니다. |
| 출현 도표 | 구간 경계, 2월·윤년, 연말 교차, 단계 미확인, 자료 없음, 출처와 마우스·클릭 동작을 검증합니다. |
| 소장 | 구매·미확인·직접 채집을 분리하고 수량 미상을 0 또는 1로 변환하지 않습니다. |
| 백업·복원 | 사용자 요청으로 보류했으며 현재 완료 기준에서 제외합니다. |
| 성능 | 수백 건의 테스트 기록과 사진에서 환경·건수·측정 방법·결과를 기록합니다. |

외부 연동은 무료 조건과 실제 응답까지 확인해야 완료입니다. 오류·미검증·보류 사항은 완료 보고에서 구분합니다.


## 현재 지도·기상 구현 범위

- 제목과 화면 전환 탭은 왼쪽 패널에 배치합니다. PC 바깥 여백과 패널 사이 간격은 모두 12px이며 왼쪽 너비는 240px로 고정합니다. 오른쪽 일반 본문 여백은 20px입니다. 지도 화면은 좌우 12px, 상하 10px이며 지도는 남은 높이를 채웁니다. 좁은 화면에서도 바깥 여백은 12px이며 620px 이하에서는 위아래 배치를 사용합니다.
- 핀 숨기기 오른쪽에 일반지도·위성지도 전환 버튼을 둡니다. 기존 지도 객체의 유형만 바꾸며 위치·핀·선택 상태를 유지합니다. 지도·기록 탭을 왕복해도 선택한 지도 유형을 유지합니다. 위성지도는 SDK의 SATELLITE 유형을 사용합니다.
- 지도 탭은 왼쪽 목록·상세, 오른쪽 지도입니다. 탐사 등록·수정은 지도와 표 모두 화면 중앙의 별도 창에서 진행합니다. 같은 좌표는 핀 하나와 기록 선택 목록으로 표시합니다. 핀 숨김은 객체를 재사용하며 지도·표 전환은 지도를 다시 생성하지 않습니다. 정보창 접기는 후속 구현입니다.
- 주소 검색은 버튼을 누를 때만 실행합니다. 좌표의 주소 확인도 별도 버튼이며 지도 이동마다 요청하지 않습니다. 주소 검색·지도 선택 후 적용 버튼으로 입력값을 반영합니다.
- 기상은 먼저 기록을 저장하고 상세에서 연결합니다. 조회 실패가 기록 등록을 막지 않습니다. 저장된 자료의 조회는 로컬 DB만 사용합니다. 현장 실측값으로 표시하지 않습니다.
- 명시적 관측소 조회·선택 후 기상을 저장하며 관찰 시각, 실제 자료 시각, 관측소·거리·출처·조회 시각·누락을 구분합니다. 시각 없는 당일 기록은 일자료 조회를 다음 날 이후로 안내합니다.
- 비용 차단은 제공자 강제 제한과 로컬 한도를 함께 사용합니다. 키·무료 적용 확인이 없으면 비활성화하며 재시도·유료 전환은 하지 않습니다. 상세 설정과 한도는 README를 따릅니다.


## 구현된 통합 검색·관찰 기록표

- 두 검색 전환 버튼 없이 왼쪽 통합 양식으로 조건을 설정합니다. 오른쪽은 관찰 기록표이며 국명·학명·장소·날짜와 선택 시각·저장 기상 다섯 열을 표시합니다. 국명은 가로 스크롤 중 고정됩니다. 나머지 결과·단계·성별·수량·채집·좌표·위치 방식·메모·수정 시각은 표시 열 선택과 상세에서 확인합니다.
- 날짜·국명·관찰 개체 수 정렬을 지원합니다. 수량 미상은 방향과 무관하게 마지막이며 미발견은 해당 없음입니다. 별도 탐사 목록에서는 직접 관찰 탐사를 조회하며 종별 기록이 0건인 탐사도 포함합니다.
- 통합 검색은 국명·학명·장소·날짜·탐사 및 종별 메모를 대상으로 합니다. 날짜 범위는 양끝 포함이며 개별 날짜를 우선합니다. 장소, 다중 종·단계·성별·결과·채집 여부, 시각·좌표 유무, 저장 기상 연결 상태 필터를 함께 적용합니다. 같은 필터의 선택은 OR, 서로 다른 필터는 AND입니다.
- 미발견 기록은 단계·성별 필터에서 제외합니다. 빈 탐사는 종별 조건이 없을 때 지도와 왼쪽 별도 항목에서 접근합니다. 필터에 맞는 종별 기록만 지도 핀의 입력으로 사용하며 좌표 없는 기록 수를 별도로 표시합니다.
- 도감 조건부 보기는 행정지역·채집 이력·소유 여부·북한 서식·미갱신 미접·국가보호종·관찰 기록 유무를 다룹니다. 현재 출현 참고 종과 출현 기준일 입력은 제거했습니다. 실제 관찰 위치 필터와 분리하며 분포로 핀을 생성하지 않습니다.
- 포획 가능 비율의 분모는 전체 등록 종입니다. 분자는 도감 조건·검색을 적용한 미채집·보호종 아님·채집 가능 확인 종입니다. 소유 전체·과별 비율은 도감 조건에 영향을 받지 않습니다.
- 하단 화면 선택은 지도 / 기록 / 나비 도감 / 자료 수집입니다. 나비 도감 탭에서는 왼쪽 공용 검색창으로 국명·학명과 표시된 상태 태그(미접·북한 서식·절멸·보호 등, 태그 안의 연도·지역 포함)를 검색하고 왼쪽 등록 양식으로 종을 추가합니다. 오른쪽은 국명·학명 / 한살이 기간 / 기주식물 / 서식지 / 습성 / 세부 정보 / 동정 포인트 표로 구성합니다. 국명을 누르면 중앙 편집창을 엽니다. 분포·미접 연도·채집·보호·출처 편집도 유지합니다. 제공된 엑셀에서 국명·학명·기주식물 282종을 반입했으며 다른 생태 자료는 임의로 채우지 않습니다. 표 셀 직접 편집·일반 대량 반입은 후속 범위입니다.
- 탐사 등록·수정 창은 기존 화면을 유지한 채 배경을 약간 어둡게 표시합니다. 탐사 공통 정보와 선택한 종별 기록을 좌우로 나누며, 여러 종별 기록은 선택창으로 전환하고 입력값은 모두 보존하여 함께 저장합니다. 오류가 있는 숨겨진 항목은 자동으로 열어 안내합니다.
- 1280×720 데스크톱 기본 배율에서 직접 관찰 기본 입력 배치를 제공하며 간접 출처·오류 안내 등 추가 항목으로 공간이 부족하면 창 내부 스크롤을 허용합니다. 좁은 화면·확대 배율·오류 안내 등으로 공간이 부족하면 창 내부 스크롤을 허용합니다. 위치 선택은 보조창에서 진행하며 탐사 취소에는 작성 계속 / 저장하지 않고 닫기를 제공합니다.

나비 기본 정보의 기본 정렬은 호랑나비과 / 네발나비과 / 흰나비과 / 팔랑나비과 / 부전나비과 순서입니다. 아과와 종은 엑셀 순서를 따르며 검은눈그물나비는 뱀눈나비아과 끝, 푸른줄까마귀왕나비는 왕나비아과 끝으로 모읍니다. 기본 정보 검색은 이 순서를 유지하고 별도 정렬 버튼을 만들지 않습니다. 분류 순서 미지정 신규 종은 뒤에 둡니다.

관찰 기록 검색의 모든 필터는 여섯 아이콘 그룹으로 제공합니다. 날짜·시각, 종, 관찰 특성(결과·단계·성별), 채집, 위치(장소·좌표), 기상 조건이며 검색 규칙은 기존과 동일합니다. 각 버튼에는 이름 안내·키보드 초점·펼침 상태·적용 상태가 있습니다. 흰색과 #fbbc04 기반 테마를 적용하고 기존 기능을 유지합니다.

지도 상단 버튼은 글자 12px·세로 여백 5px로 줄이고, 핀 버튼과 지도 종류 버튼 묶음의 간격은 지도 좌우 여백과 같은 12px입니다. 일반지도·위성지도는 서로 붙인 버튼 형태이며 낮춘 높이를 유지합니다. 외부 연결 안내 문장은 지도 하단 저장 안내 영역에 표시합니다. 하단 저장 안내는 구분선 없이 기존보다 1pt 작은 글자와 절반의 세로 여백을 사용합니다. 확보한 공간은 지도 높이에 반영합니다.


## 통합 표의 출처와 참고 행 규칙

- 표의 관찰 행은 한 건당 한 행이며 여러 장소·날짜를 대표 기록 하나로 줄이지 않습니다. 기본 열은 국명·학명·장소·시간·기상입니다. 분류 순서가 기본이며 날짜·국명·개체 수·남은 출현 일수 정렬을 제공합니다.
- 검색 필터에서는 직접 / 간접 관찰을 동시에 또는 개별 선택할 수 있습니다. 한 탐사를 등록할 때는 둘 중 하나만 선택합니다. 간접 출처 근거는 필수이며 사용자 채집 이력과 원 관찰자의 채집 기록을 구분합니다. 네이처링 확장 수집은 사용자가 시작하고 선택 등록하며, iNaturalist는 공식 API로 수집하고 사용자 선택으로 등록하며 웹 자료는 원문 확인 후 대기함에 직접 입력해 검수 등록합니다.
- 기록에서는 관찰 조건을 펼침 양식으로, 지도에서는 여섯 아이콘으로 표시하며 관찰 필터 상태를 공유합니다. 출현·채집 목표 조건은 도감 조건부 보기에서 별도로 적용합니다.
- 관찰 기록 없는 종 포함 조건은 도감에만 적용합니다. 관찰 기록표는 실제 기록만 표시하며 지도에서 검색한 종의 참고 분포는 실제 관찰 핀으로 바꾸지 않습니다.
- 관찰 행은 탐사 상세·수정으로 연결합니다. 종 정보 조회·편집은 나비 도감에서 수행합니다.
- 도감 제목 행 우측 박스의 포획 가능 종 비율은 도감 검색 결과의 종을 중복 없이 집계합니다. 분모는 전체 등록 종, 분자는 미채집·보호종 아님·해당 목표 지역·기간의 채집 가능이 모두 확인된 종입니다. 미확인은 분자에서 제외합니다.
- 참고자료 요청 중·실패 상태를 표시하고 다시 읽기를 제공합니다. 탐사 조건을 적용한 상태에서 참고자료를 읽지 못하면 조건을 무시한 결과를 표시하지 않습니다.

## 구현된 환경 태그

등록·수정창에서 탐사 공통 태그와 종별 추가 태그를 접고 펼칩니다. 기본 항목과 직접 추가한 이름을 체크박스로 선택하며 검색창에서 이름을 찾아 새 항목을 추가할 수 있습니다. 선택하지 않은 항목을 부재로 해석하지 않습니다. 추가 중에는 기록 저장을 잠시 막고, 실패하면 입력과 기존 선택을 유지합니다. 새 이름은 즉시 로컬 목록에 기억되며 기록 취소와 별개입니다.

출처·관찰 특성 필터 안에서 환경 태그를 검색·선택합니다. 선택 태그 중 하나 이상이면 해당 그룹에 일치하고 다른 조건과는 모두 만족해야 합니다. 관찰 기록표의 선택 열에서 환경 태그를 표시할 수 있습니다. 상세에서는 공통 태그와 개별 태그를 구분합니다. 습성은 도감에서 관리하며 자동 태그 분류나 태그 이름 변경·통합·삭제는 구현하지 않습니다.

별도 시험 DB에서 등록·수정·재조회, 새 입력에서 이름 기억, 중복·빈 이름·과다 입력, 미발견·간접 관찰, 공통·개별 복합 검색, 빈 결과, 통신 실패 후 입력 유지·재시도를 확인했습니다. 1280×720에서 태그를 접은 기본 입력 화면의 내부 세로 스크롤이 없음을 확인했습니다. 태그를 펼치면 목록 또는 창의 스크롤을 사용할 수 있습니다. 실제 지도 타일·마커 재검증은 외부 API 비용을 피하기 위해 수행하지 않았으며 로컬 필터 연결과 지도 오류 상태·핀 숨김·탭 전환만 점검했습니다.


## 구현된 나비 도감 상태 요약

국명·학명 아래에 해당 상태만 줄바꿈 가능한 태그로 표시합니다. 멸종위기 I급·II급은 옅은 적색, 천연기념물은 황갈색, 지역보호[경기도]는 주황색, 미접[2025]는 청색, 북한 서식은 보라색, 절멸은 회색 계열입니다. 색과 함께 글자로 의미를 구분하고 마우스를 올리면 출처를 표시합니다. 미접 연도는 등록된 확인 자료 중 최신 연도 하나만 표시하며 연도 미상은 명시합니다. 태그가 없다고 해당 없음으로 확정하지 않습니다.

미접으로 분류된 종은 사용자 확인(user_confirmed)된 국내 간접 관찰의 실제 관찰 날짜(개별 날짜 우선, 없으면 탐사 날짜) 중 최신 연도로 갱신합니다. 수집함 자료·동정 후보·미발견·휴지통·해외·국내 여부 미확인은 제외하며 발표일·게시일을 사용하지 않습니다. 국내 여부는 명시된 국내 주소, 현재 위치와 일치하는 iNaturalist 원문의 대한민국 place_ids(6891), 또는 사용자가 관찰의 종별 태그로 지정한 ‘국내 관찰 확인’으로 확인합니다. 좌표 범위만으로 판정하지 않습니다. 자동 갱신을 시작하면 기존 연도를 누적하거나 복원하지 않습니다. 관찰 수정·삭제·복구·검수 취소에 따라 다시 계산하며 확인 사례가 모두 없어지면 연도 미상으로 표시합니다. 근거 관찰 번호·날짜·출처를 보존합니다. 미접 분류와 국내 정착 여부 자체는 자동 변경하지 않습니다.

국명을 눌러 여러 보호 지정과 지역·출처·확인일, 북한 서식·미접·목격 연도, 국내 절멸과 출처를 편집할 수 있습니다. 상태 자료 원문·셀 출처는 편집창에서 확인합니다. 지역보호는 국가보호종 제외 필터와 구분합니다. 절멸은 국내 기준의 별도 분류이고 자동 제외 필터는 추가하지 않습니다. 큰수리팔랑나비에는 사용자 지정 절멸과 보호정보 확인 필요를 함께 표시합니다.


## 구현된 사진과 촬영 정보

- 탐사 공통과 종별 기록에 사진·촬영 정보를 따로 연결합니다. 새 탐사와 수정 화면의 사진 관리 창에서 검사·후보 확인·선택 등록을 하고 탐사 저장으로 연결합니다.
- 촬영 정보만 보관하는 것이 기본이며 증거 사진으로 선택한 파일만 data/photo에 복사합니다. 원본은 변경하지 않고 미리보기는 별도 생성합니다. 같은 파일 내용은 재사용합니다.
- 촬영 날짜·시각과 GPS는 각각 사용자가 적용해야 입력란에 반영됩니다. 탐사에는 날짜만, 종별 기록에는 날짜와 선택 시각을 적용합니다. GPS 적용 시 기존 장소명을 비우며 주소·기상 자동 조회는 하지 않습니다. 지도 사용은 기존 네이버 연동 범위를 따릅니다.
- 파일명·원문 촬영 시각·시간대·추출 좌표·기기명 등을 보존하고 촬영 정보가 없거나 잘못된 경우 명시합니다. 날짜를 파일명이나 파일 생성일로 추측하지 않습니다. 시간대 미상은 확인 경고를 표시합니다.
- 처리는 순차 진행·중단·재시도를 지원합니다. 실패한 파일과 입력은 유지하고 정상 처리한 다른 항목을 자동 삭제하지 않습니다. 파일 검사와 목록에 진행·오류·등록 상태를 표시합니다.
- 기록 상세에는 정보만 보관한 항목과 증거 사진을 구분하고 미리보기·원본 내려받기를 제공합니다. 기록에서 연결 해제하더라도 원본은 자동 삭제하지 않습니다. 보관 자료 목록에서 다시 연결할 수 있습니다.
- JPEG·PNG 정지 사진, 한 장 최대 32MiB·6000만 화소, 한 번에 2000장과 기록당 2000개 연결을 지원합니다. HEIC와 동영상은 후속 범위입니다. 목록은 12개씩 나누며 썸네일은 지연 로딩합니다. 서로 다른 원본 1400장의 브라우저 전체 처리 성능은 미검증입니다.


## 구현된 소장 목록

- 하단 기록 화면의 표 종류에 소장 목록을 추가합니다. 왼쪽 공용 검색창과 소장 등록·취득 경로·소지 상태·성별 필터를 사용하고 오른쪽은 목록 표로 표시합니다. 지도·나비 도감과 기존 관찰·탐사 표 기능을 유지합니다.
- 종·성별·소지 상태·선택 수량·취득 경로·선택 날짜·직접 채집 관찰 연결·근거·메모·사진을 등록하고 수정합니다. 성별은 수컷·암컷 체크박스 중복 선택이며 둘 다 선택하면 총수량을 2개체 이상 필수 입력합니다. 성별 세부 수량은 둘 다 비우거나 총수량과 합계가 같도록 함께 입력합니다. 국명을 누르면 중앙 편집창을 열고, 원래 내역이 여러 건이면 성별 내역에서 수정할 기록을 선택합니다. 통신·검증·편집 충돌 오류가 나면 입력을 유지합니다.
- 같은 종·같은 취득 경로는 표에서 한 행으로 묶고 암수 모두 있으면 수컷 / 암컷으로 표시합니다. 원본 기록의 성별 수량·취득 근거·날짜·사진은 보존합니다. 소장 개체 수에 마우스를 올리거나 키보드 초점을 맞추면 수컷 n개체 / 암컷 m개체를 표시하며 미상은 추정하지 않습니다.
- 현재 소장 종 수·알려진 수량·수량 미상 건수를 구분합니다. 서로 다른 취득 건은 저장소에서 자동 병합하지 않습니다. 미체크·미확인·수량 미상에서 개인 채집이나 수량 1을 추정하지 않습니다.
- 구매·기타·미확인으로 개인 관찰이나 채집 이력을 만들지 않습니다. 직접 채집만 근거와 함께 과거 채집 이력 판단에 반영하며 연결 관찰의 종·출처·채집 수량을 검증합니다. 소장 사진의 촬영 날짜와 GPS는 취득 날짜·위치로 적용하지 않습니다.
- 사용자용 백업·복원은 사용자 요청에 따라 이번 범위에서 제외합니다. 기존 DB 이전의 자료 보존용 복사본 생성과 롤백 규칙은 유지합니다.

## 자료 수집 화면

네이처링 확장 0.4.3의 ‘현재 기록 읽기’는 위치 없는 자료도 수동으로 보관·전송합니다. 대기함에서 선택·종 및 성장 단계 수정·삭제·간접 관찰 등록을 지원합니다. 비공개 지도 좌표는 읽지 않으며 연속 자동전송은 계속 위치 없는 자료를 제외합니다. 위치 없는 간접 관찰은 기록 표에서 확인하고 지도 핀이나 관찰 지역 근거로 사용하지 않습니다.

- 관찰 상세의 탐사 메모와 종별 출처에 포함된 HTTP·HTTPS 원문 주소는 주소 그대로 표시하는 하이퍼링크로 제공합니다. 클릭하면 새 탭으로 열며 저장된 원문은 변경하지 않습니다.
- 탐사 등록·수정창의 입력 항목 이름은 굵게 표시하며 입력값과 보조 설명은 일반 굵기를 유지합니다. 글자 크기와 배치는 유지합니다.
- 나비 도감 오른쪽에 자료 수집 탭을 표시합니다. 왼쪽에서 내 사진·iNaturalist·네이처링·논문 탐색·구글링을 선택하고 오른쪽에서 선택한 수집처와 준비 상태를 확인합니다.
- 네이처링 확장은 연결 키로 현재 기록 및 보관 자료를 로컬 DB에 전송합니다. 수집 화면에서 25건 단위 목록을 조회합니다. 같은 관찰 번호는 중복을 방지하고 변경 전 내용을 보존합니다. 개인 탐사·지도·통계에는 자동 편입하지 않습니다. iNaturalist는 공식 API 수집·선택 등록을 지원합니다. 네이처링 자료는 사용자 선택 등록 후 지도·표와 조건에 맞는 한살이 통계에 반영합니다. 사진 파일의 별도 다운로드는 실행하지 않습니다.
- 네이처링 자동전송은 사용자가 누르면 시작 페이지 다음의 관찰을 끝까지 이동·추출·보관·DB 전송합니다. 상단 다음 관찰 링크의 검색 조건을 유지하며 DB 전송을 마치고 다음 링크가 준비되면 추가 대기 없이 순차 이동합니다. 팝업을 닫아도 실행되고 다시 열어 중지할 수 있습니다. 다음 링크 없음·반복 링크·다른 페이지 이동·로딩 시간 초과·추출 및 전송 실패 시 종료합니다. 확장 재로드나 브라우저 재시작 시 자동 재개하지 않습니다. 연속 전송은 사용자 Chrome에서 작동을 확인했습니다. 확장 재시작 후 자동 재개와 별도의 대량 수집 안정성 검증은 제공하지 않습니다. 게시자 위치 비공개 안내가 있으면 좌표를 읽거나 전송하지 않고 다음 관찰로 진행합니다.
- 수집 표의 행 선택과 머리글 전체 선택은 현재 페이지의 모든 자료에 적용합니다. 등록 버튼은 선택 중 등록 가능한 미등록 자료만 추가합니다. 선택 자료 등록 버튼으로 간접 관찰에 추가하며 원문과 등록 연결을 보존해 중복을 막습니다. 검토 필요·도감 추정 단계를 목록에 표시합니다. 등록된 자료는 수집 목록에서 빠지고 응답의 변경 탐사를 공유 목록에 병합합니다. 이전 서버 응답이나 초기 자료가 없는 경우 전체 조회로 보완합니다. 등록된 관찰은 관찰 상세의 삭제 버튼으로 휴지통에 옮깁니다.
- 선택 자료 삭제는 확인 후 수집 목록에서만 숨기고 이미 등록한 관찰을 유지합니다. 같은 자료의 재전송으로 다시 나타나지 않습니다. 원문과 이력은 DB에 보존됩니다.
- 가져온 기상은 등록 당시 원문 스냅샷에서 관찰 표·상세와 기상 연결 상태 필터에 반영합니다. 출처는 네이처링으로 표시하고 기상청 조회를 자동 실행하지 않습니다. 기존 등록 자료에도 적용하며 관찰 조건 변경 시 이전 조건 자료로 표시합니다. 기상청 연결값이 있으면 표에서는 그 값을 우선 사용합니다.
- 관찰 기록표의 실제 관찰 행은 한 번 클릭하면 선택하고 더블클릭하면 중앙 상세 팝업을 엽니다. 국명 버튼에서 Enter로도 열 수 있습니다. 표 아래 상세는 표시하지 않으며 팝업 뒤 화면은 새 탐사와 같은 정도로 어둡게 처리합니다. 닫기·Esc로 닫고 팝업에서 기존 수정·삭제·사진·기상 기능을 사용합니다. 삭제 화면으로 이동할 때 상세 팝업은 닫힙니다. 수정은 같은 팝업 안에서 진행합니다. 관찰 기록표에 도감 참고 행은 표시하지 않습니다.
- 상세 팝업의 기록 수정은 같은 팝업 안에서 기존 탐사 수정 폼으로 전환합니다. 더블클릭한 관찰을 기본 선택해 단계·성별·수량·메모·위치 등을 수정하고 저장 후 상세로 돌아옵니다. 편집 중 닫기·Esc·취소는 저장하지 않고 닫을지 확인하며 취소하면 기존 상세를 유지합니다. 직접 수정한 단계는 도감 추정 표시를 해제하고 원래 추정과 수동 변경 이력을 보존합니다.
- 확장 프로그램은 위치 비공개·미입력 안내, 빈 위치와 유효한 공개 위도·경도 쌍이 없는 자료를 보관·DB 전송·내보내기에서 제외합니다. 비공개나 미입력 안내가 있으면 지도 요소의 기본 좌표도 읽지 않습니다. 연속 수집은 제외 건수를 표시하고 다음 관찰로 계속 진행합니다. 기존 확장 보관 자료에도 전송 직전 같은 검사를 적용하며 이미 앱 DB에 저장한 자료는 자동 삭제하지 않습니다.
- 모든 종은 대기함에서 사용자가 검수한 뒤 선택 등록합니다. 종별 검수 생략 예외는 사용하지 않습니다.
- 원본 관찰 날짜를 유지하고 도감 한살이 기간에서 단계를 추정합니다. 겹치는 기간은 뒤 단계를 사용하며 일치 기간이 없으면 미확인으로 등록합니다. 등록 당시 도감 근거와 추정 표시를 보존합니다.
- 지도 핀은 직접 관찰 주황색, 네이처링 파란색, iNaturalist 녹색, 그 외 간접 관찰 회색으로 표시합니다. 간접 관찰 출처 주소의 호스트로 출처를 판별합니다. 같은 좌표는 기존처럼 핀 하나로 묶되 출처가 섞이면 해당 색을 함께 표시하고 위치별 기록 목록에 출처명을 표시합니다. 출처 조합이 바뀔 때만 기존 핀 아이콘을 갱신하며 핀 숨김·표시로 DB를 다시 조회하지 않습니다. 직접 관찰이 포함된 핀은 다른 관찰 핀보다 위에 표시합니다. 같은 위치의 기록 목록과 핀 클릭의 첫 선택도 직접 관찰을 우선하며 나머지 출처 정보와 원래 순서는 보존합니다. iNaturalist 공식 API 수집과 선택 등록도 지원합니다.

## 구현된 탐사·관찰 휴지통

- 상세에서 탐사 전체 또는 관찰 한 건을 확인 후 휴지통으로 이동합니다. 삭제 기록은 일반 조회·지도·표·검색·관찰 집계에서 제외하며 실제 행과 원본 파일은 지우지 않습니다.
- 왼쪽 휴지통에서 복구합니다. 탐사 삭제는 자식 관찰을 함께 숨기며 탐사 복구 시 그 전에 따로 삭제한 관찰은 계속 숨깁니다. 개별 관찰 복구는 탐사 복구 후에 가능합니다.
- 사진·태그·메모·저장 기상과 원래 연결을 보존합니다. 소장 연결이 있는 관찰은 소장 화면에서 연결을 먼저 해제해야 삭제할 수 있습니다. 소장 자체와 직접 채집 근거를 자동 삭제하지 않습니다.
- 삭제·복구는 외부 API 호출 없이 로컬에서 처리합니다. 오래된 편집창의 수정·삭제 요청과 중복 복구는 충돌로 거부하고 DB 오류는 전체 작업을 되돌립니다. 휴지통 항목별 완전 삭제를 지원하며 휴지통 전체 삭제는 별도 확인 후 지원하며 소장·종 정보 삭제는 제공하지 않습니다.

- 모든 종은 사용자가 체크하면 검수 완료로 보고 등록합니다. 체크박스는 모든 행에서 선택할 수 있습니다. 등록 가능 여부는 날짜·도감 종 연결·위치 등 필수 정보의 유효성과 기존 등록 여부만 판단합니다.

- 과거 개별 반입 기록(현재 DB 값을 대신하지 않음) — 모시나비 사용자 제공 기간표: 알 6월 11일~2월 말일, 애벌레 3월 1일~5월 15일, 번데기 5월 1~15일, 어른벌레 5월 6일~6월 15일. 도감명·판본은 미확인이며 사용자 제공 자료임을 출처로 보존합니다. 기간 중첩은 뒤 단계로 추정하고 실제 사진 검수 결과와 구분합니다. 기존 모시나비 가져오기 자료 중 미확인 단계만 이번 제공 자료로 보완했습니다.

### 목록·도감 표시 성능

### 도감 개조식 표시와 자료 반입

- 동정 포인트는 종 구분·암수 구분을 나누고 습성·기타와 함께 개조식으로 저장합니다. 도감 표에서는 각 `-` 줄을 실제 글머리 점으로 표시합니다.
- 암수 구분은 필요한 진단 특징 중심으로 적으며, 다른 성별의 항목을 채우려고 대응되는 부재 설명을 추가하지 않습니다. 사용자 지정에 따라 왕그늘나비의 암컷 털 뭉치 부재 문장은 생략합니다. 종 구분에 필요한 무늬의 부재는 유지하며, 개체 변이·추정·경향 표현을 일괄 제거하지 않습니다.
- 날개 부위는 사용자 제공 도해의 한글 명칭을 따릅니다. 전연은 앞가장자리, 외연은 바깥가장자리, 앞날개 후연은 뒷가장자리, 뒷날개 후연은 안가장자리, 후각은 날개뒤로 표현합니다. 앞날개·뒷날개와 윗면·아랫면, 맥·실을 구분합니다.
- 무늬의 위치는 종 동정에 필요한 수준으로만 적습니다. 모양·색·유무만으로 사용자 지정 비교 범위의 종을 구분할 수 있다면 세부 위치나 실 번호를 추가하지 않습니다. 위치가 구별점이면 필요한 부위·면·실을 정확히 적고 도해만으로 실제 무늬 위치를 추정하지 않습니다. 사용자 제시 예: 붉은점모시나비는 국내 종 비교에서 붉은 점의 특징으로 구분하므로 뒷날개 7실·4실까지 덧붙이지 않습니다. 이 기준을 근거로 다른 종의 기존 위치 설명을 일괄 삭제하지 않고 종별 필요성을 검토합니다.

- 종 자체의 활동 시간·비행·텃세 등은 습성에, 강우·위협 등 외부요인에 따른 관찰 사례는 기타의 관찰된 특징에 기록합니다. 날개 부위와 날개 면을 구분하며 전체적인 바탕색에는 특정 부위·면을 임의로 붙이지 않습니다.
- 사용자 엑셀의 빈 셀은 기존 자료 삭제 지시로 취급하지 않습니다. 한살이의 여러 발생 구간·연말 연결과 원래 관찰 날짜를 유지하고, 도감 반입으로 기존 관찰 단계를 재분류하지 않습니다. 출처는 사용자가 제공한 서지정보임을 구분하여 보존합니다.

- 암수 구분 문장은 `수컷: 특징`, `암컷: 특징`, `공통: 특징` 형식으로 통일합니다. 같은 성별의 연속 항목은 화면에서 한 글머리 점으로 묶고 성별은 한 번만 표시합니다. 이어지는 설명과 자동 줄바꿈은 첫 설명의 시작 위치에 맞춰 들여씁니다. 특정 부위가 없는 바탕색 설명은 날개 전체에 대한 설명으로 유지합니다. 도감의 동정 본문은 12px, 제목은 13px, 기타의 참고 문헌 항목은 10px로 표시합니다. 행 기본 높이는 152px이며 긴 내용은 잘리지 않도록 확장합니다.

- 동정 설명에서 대상의 단순 색은 `[대상]은 [색]임`, 명시된 바탕색은 `[대상]은 [색] 바탕` 형식으로 통일합니다. 단순 색 서술의 `검음·흼·○○색을 띰`은 같은 의미의 `검은색임·흰색임·○○색임`으로 정리합니다. 단순히 색이 적혀 있다는 이유로 바탕색으로 바꾸지 않습니다.
- 색이 있는 무늬의 존재는 `[위치]에 [특징·색] [무늬]가 있음` 형식으로 적습니다. 무늬 앞에서는 흰·검은·노란·붉은·푸른 등 자연스러운 형용사형을 사용하며, `흰색의 무늬·검은색 무늬·노란색을 띠는 줄무늬`처럼 같은 색을 달리 서술하지 않습니다. 갈색·주황색·상아색 등은 색 이름을 그대로 수식어로 사용합니다. 기존 무늬의 개수·배열·부재·조건은 보존하며 `많음·나열됨·흐리거나 없음`을 단순한 있음으로 축소하지 않습니다.
- 광택은 `[위치]에 [색] 광택이 있음` 형식으로 적습니다. `연둣빛이 도는 유백색·보랏빛이 도는 황갈색·노란빛` 등의 색감, 반투명함·투명도, 비교·경향·정도 표현은 별도 의미이므로 단순 색 서술로 바꾸지 않습니다. 색 이름 자체를 다른 색 이름으로 교체하지 않습니다.
- 상대적인 색의 진하기는 `[대상]이 더 진함/연함` 형식으로 적되, 밝음·어두움·짙음·옅음이 원문에서 서로 다른 의미일 수 있으므로 일괄 치환하지 않습니다. 무늬의 면적·농도, 색이 나타나는 범위, 선명도, 투명도도 서로 바꾸지 않습니다. 특정 날개·윗면·아랫면이 명시된 경우 그 범위를 유지하며, 눈·몸통·점·무늬 색을 날개 바탕색으로 바꾸지 않습니다. 모호한 문장은 원문을 보존하고 확인 대상으로 기록합니다.

휴지통 전체 삭제는 새로고침 오른쪽에서 실행하며 삭제 전 대상 수를 확인합니다. 목록 변경 시 재확인이 필요하고 보호 복사본 생성 실패 시 삭제하지 않습니다. 나비 도감의 제목과 표 머리글은 세로 스크롤 중 고정하고 나비 목록만 스크롤합니다. 기존 가로 스크롤은 유지합니다.


## 출현 행정지역과 종별 목록

- 도감 표에는 열을 추가하지 않습니다. 종 기본 정보 팝업에서 수도권·강원도·충청권·전라권·경상권·제주를 펼쳐 시도·시군구 체크박스를 관리합니다. 상위 전체 선택·해제와 일부 선택 상태를 표시합니다. 엑셀 참고·사용자 지정·사용자 확인 관찰의 근거를 함께 보되 원문은 구분합니다. 수동으로 해제한 지역은 제외 상태를 보존하며 자동으로 다시 체크하지 않습니다.
- 나비 도감 검색에는 출현 행정지역의 현재 이름·이전 이름·권역을 포함합니다. 엑셀 출현지역만 별도로 반입하며 다른 한살이·동정·보호종 자료는 덮어쓰지 않습니다. 빈 셀은 미서식 근거가 아닙니다.
- 사용자 확인된 실제 관찰의 좌표 또는 명확한 주소에서 지역을 연결합니다. 개별 위치 우선·탐사 위치 상속을 지키고 좌표는 로컬 경계에서 판정합니다. 후보·미발견·휴지통은 지역 자동 추가에서 제외합니다. 같은 지역은 한 번만 표시하되 사례별 근거는 보존합니다. 수정·검수 취소·삭제·복구에 따라 관찰 근거를 다시 계산하며 엑셀·사용자 지정 근거는 남깁니다.
- 한라(엑셀 원문)는 사용자 확인에 따라 한라산으로 연결합니다. 한라산은 공개 고도 자료에서 추출한 해발 1,000m 이상 등고선 기준의 사용자 지정 참고 지역이며 실제 서식 고도 하한이나 국립공원 경계가 아닙니다. 마라도는 SGIS 섬 도형을 분리한 별도 참고 지역으로 관리합니다.
- 지도 출현지역은 핀 숨기기 왼쪽의 같은 규격·간격 버튼으로 보기·숨기기를 전환합니다. 상세 안내·출처는 하단 외부 연결 안내 오른쪽에 이어 표시합니다. 레이어는 녹색이며 기본 꺼짐이고 왼쪽에서 선택하거나 정확한 종명 검색으로 지정한 한 종만 표시합니다. 여러 종의 레이어는 합치지 않습니다. 엑셀·사용자 지정은 옅게, 관찰 확인 지역은 진하게 표시하며 클릭하면 근거를 보여줍니다. 행정·고도 경계 파일은 로컬에서 재사용하고 출처를 표시합니다. 기존 관찰 핀과 분리합니다.
- 출현지역 도형은 지도 화면과 사방 20% 여백에 걸치는 부분만 표시하고 지도 이동 종료·크기 변경 후 갱신합니다. 같은 지역은 재사용하고 관찰 근거 변화는 색상만 갱신합니다. 확대 수준 8 이하·9~11·12 이상에 따라 표시 경계를 선택하며, 12 이상은 기존 원본의 작은 섬도 포함합니다. 지역 판정 원본과 마라도·한라산 경계는 유지합니다.
- 도형 생성·표시·숨김은 한 프레임에서 최대 12개 또는 약 5ms 작업 후 다음 프레임으로 넘깁니다. 개별 SDK 호출 시간은 이 한도를 넘을 수 있습니다. 종 변경·숨김·탭 전환 시 미완료 작업을 취소합니다. 도형 캐시가 600개 또는 꼭짓점 100,000개를 넘으면 숨긴 도형부터 정리하며, 현재 화면의 도형은 유지합니다. 경계 파일 요청은 단계별로 재사용하고 통신 실패 시 다시 시도할 수 있습니다.

- 왼쪽 종별 기록은 도감 표시 순서로 종당 카드 하나를 표시합니다. 제목 오른쪽은 검색 조건에 맞는 실제 관찰 종 수이며 건수·개체 수·참고 종·미발견·종 미확정을 포함하지 않습니다. 카드에는 시도·시군구 지역 요약, 관찰 기록 수, 직접·간접 건수, 별도 미발견 건수와 최근 실제 관찰일을 표시합니다. 검색 지역을 먼저 보이고 기본은 직접 관찰 지역을 우선합니다.
- 종 선택은 오른쪽 표·핀의 해당 종 기록을 좁힙니다. 개별 기록 상세·수정·삭제는 유지하고 종 미확정·빈 탐사는 별도 접기 항목으로 접근합니다. 화면에서만 묶으며 관찰 원본은 병합·삭제하지 않습니다.
### 지역명 표시 보정

- 종별 기록 목록은 가나다순 대신 도감의 분류 표시 순서를 따릅니다. 오른쪽 숫자는 검색 조건에 맞는 관찰 종 수이며, 미발견·동정 미확정·도감 참고 행은 종 수에 포함하지 않습니다.
- 탐사·관찰 표와 상세, 외부 수집 대기함의 장소 표시는 로컬 경계로 확인한 정식 행정지역을 사용합니다. 강원·강원도 등 이전 이름과 원문 영어 지명도 검색할 수 있습니다. 영어 장소를 임의 번역하지 않고 국내 좌표로 행정지역을 확인합니다. 확인되지 않는 위치는 원문을 유지합니다.
- 원본 장소·좌표·외부 수집 원문은 변경하지 않습니다. 상세 화면과 수집함에서는 보정 장소명과 좌표를 표시하며 장소 원문을 별도로 표시하지 않습니다. 수정창은 저장된 원문을 편집합니다.
- 경계는 SGIS 2025-06-30 자료입니다. 확인된 명칭 변경을 표시에 반영하되, 이후 개편된 인천 옛 중구·서구의 새 세부 구역은 이 경계만으로 확정하지 않으며 확인 필요로 표시합니다. 전남광주통합특별시의 옛 광주·전남 참고 범위도 구분합니다. 경계 자체가 최신 행정구역으로 갱신됐다는 의미가 아닙니다.

수집 대기 자료는 네이처링·iNaturalist 모두 행 더블클릭 또는 행에 초점을 두고 Enter를 눌러 종과 성장 단계를 수정합니다. 알·애벌레·번데기·어른벌레·미상 중 고르고 단계 저장으로 해당 자료를 덮어씁니다. 저장만으로 관찰 기록을 생성하지 않으며 기존 선택 등록 절차를 유지합니다. 사용자 지정은 도감 추정과 구분하고 재수집해도 유지합니다. 취소는 변경하지 않으며 오류 시 입력을 유지합니다. 이미 등록되거나 삭제된 자료와 다른 창에서 변경된 자료의 수정은 거부합니다.

### 수집 안정성과 지도 기록 연결

- iNaturalist는 50건 단위로 최대 40번(최대 2000건) 확인하며, 저장한 ID 진행 위치로 재개합니다. 과거 수집 이력이 없는 첫 최신 수집의 200건은 여러 요청으로 받습니다. 12MB 응답 제한·공개 위치 조건·중복 방지·수동 단계 보존·일일 5000회와 요청 간 최소 간격은 유지합니다. 통신·서버 일시 오류는 2초 뒤 한 번 재시도하고 각 시도를 사용량에 포함합니다. 429는 자동 재시도하지 않습니다. 화면 대기는 검색 45초·수집 90초입니다.
- 수집 목록은 장소 열의 너비를 고정 범위로 유지하고 긴 주소를 한 줄 끝에서 페이드아웃합니다. 주소 원문은 보존하며 마우스를 올리면 전체 주소를 확인할 수 있습니다. 좌표와 출처 열은 별도로 표시합니다.
- 지도 핀 선택 후 위치 기록 버튼을 더블클릭하거나 Enter로 열면 기록 탭으로 전환하고 해당 탐사의 중앙 상세 팝업을 엽니다. 직접 관찰은 탐사 목록, 간접 관찰은 관찰 기록을 선택합니다. 단일 클릭 선택은 유지합니다.

### 기록 목록과 도감 조건부 보기

- 한 탐사에는 직접 또는 간접 관찰 하나만 선택합니다. 출처는 탐사 공통 항목이며 추가한 종별 기록도 같은 출처를 사용합니다. 혼합 입력은 API에서도 거부합니다.
- 기록 탭의 관찰 기록은 실제 기록만 표시합니다. 탐사 목록은 직접 관찰 탐사를 표시하며 종별 기록이 0건인 탐사도 포함합니다. 날짜·장소·메모·공통 태그와 직접 관찰 출처 조건으로 찾을 수 있습니다. 종·성장 단계·성별·관찰 결과·채집·관찰 시각·기상 등 개별 관찰 조건을 지정하면 종별 기록 없는 탐사는 제외합니다. 온라인 자료 조사와 간접 관찰 탐사는 포함하지 않으며, 간접 관찰은 관찰 기록에서 조회합니다.
- 관찰 기록 행은 72px로 통일합니다. 긴 내용은 목록에서 제한하고 상세에서 확인합니다. 정렬 결과를 재사용하고 남은 화면 높이를 표로 채우고 실제 표 영역 높이에 맞는 행 수와 여유 16행만 그려 표시 열 선택 시 전체 기록을 다시 그리지 않습니다.
- 행정지역, 채집 이력, 북한 서식, 미갱신 미접, 국가보호종, 관찰 기록 없는 종 포함 조건은 도감의 나비 등록 아래 도감 조건부 보기에 둡니다. 나비 등록은 기본적으로 접습니다. 도감 조건은 지도·기록의 관찰 필터에 적용하지 않습니다.
- 소유 여부는 전체 / 소유한 종 제외 / 소유한 종만 보기 중 하나를 선택합니다. 소장 목록에서 구매 또는 직접 채집으로 소지 중인 기록이 하나 이상 있는 종을 소유한 종으로 계산하며 미확인 상태를 소유로 추정하지 않습니다.
- 포획 가능 종 수·비율은 나비 도감 제목과 같은 행의 우측 끝 둥근 박스 가장 왼쪽에 표시합니다. 소유 여부를 포함한 도감 조건·검색 결과를 분자에 적용하고 분모는 전체 등록 종입니다. 그 뒤 전체 소유 비율과 도감 분류 순서의 과별 소유 비율을 표시합니다. 전체·과별 비율은 전체 도감 및 소장 자료로 계산하고 조건·검색에 영향을 받지 않습니다. 비율 박스는 조건부 보기의 접힘과 무관하게 표시하며 제목 행의 상하 간격을 늘리지 않습니다.


### 도감의 굵기·폭·두께 표현

국립국어원의 사전 뜻풀이와 온라인가나다 답변을 참고하여 다음 작성 기준을 사용합니다. 국립국어원이 나비 무늬에 대해 직접 정한 규정은 아니며, 단어를 대상·문맥에 맞게 구별하기 위한 프로젝트 규칙입니다.

- 선형 무늬·막대·띠의 가로 크기는 폭이 넓음 / 폭이 좁음으로 명시합니다. 선에 굵다·가늘다를 쓰는 것 자체를 오류로 단정하지 않습니다.
- 개별 털·더듬이 등 길쭉한 구조의 굵기는 굵다 / 가늘다로 구별합니다.
- 실제 물체·막·층의 두께는 두껍다 / 얇다로 구별합니다. 물리적 두께 설명을 폭이나 면적으로 바꾸지 않습니다.
- 색·광택이 차지하는 면적·범위는 나타나는 범위가 넓음 / 좁음으로 명시합니다. 빛의 강도·선명도·개체 변이와 혼동하지 않습니다.
- 폭·두께·범위 중 무엇을 뜻하는지 불명확하면 원문을 유지하고 사용자에게 확인합니다. 기존 아과별 분할 검토 순서를 유지하며 다른 아과까지 일괄 치환하지 않습니다.

- 세부 정보 항목은 기주식물(사육), 활동 시간, 관찰된 특징, 월동·휴면, 사육 환경, 번식·산란, 표본 제작·보존, 기타 메모입니다. 같은 항목에 여러 사례를 저장할 수 있습니다. 기주식물(사육)을 제외한 항목의 제목·본문·출처는 필수이고 근거 유형은 야외 관찰·사육 기록·문헌 정리·추정 중 선택합니다. 적용 범위와 자료·관찰 시점은 선택 입력합니다.

- 네이처링과 iNaturalist 수집 대기함은 왼쪽 수집처 설명과 휴지통 사이의 접이식 검수 리모컨에서 현재 페이지 전체 선택·해제, 새로고침, 선택 등록·삭제를 지원합니다. 삭제 확인은 리모컨의 삭제 버튼 아래에 표시합니다. 표 제목 행은 스크롤 중 화면 상단에 닿으면 고정되고 역방향 스크롤 시 원래 위치로 돌아옵니다.


### 모바일 사진 메타데이터 전송

- PC의 자료 수집에 내 사진 수집처와 접이식 연결 관리·대기함을 제공합니다. 수신만으로 탐사·관찰을 만들지 않습니다. 선택 사진의 날짜·위치를 검수해 종별 기록 없는 탐사를 먼저 등록합니다.
- 같은 탐사의 사진 여러 장을 사용자 선택으로 묶고 날짜·위치가 다르면 검수값을 직접 지정합니다. 등록 완료 후 관찰 추가하기를 누르면 기록 탭의 기존 수정 창이 열리고 종별 기록 추가로 여러 종을 입력합니다. 종·성장 단계는 사용자 입력이며 사진 촬영 시각을 모든 종의 관찰 시각으로 자동 복사하지 않습니다. 사진 정보는 탐사 공통 연결에 남고 PC에서 원본을 나중에 추가할 수 있습니다.
- 브라우저는 선택한 JPEG·PNG의 촬영 원문·시간대·GPS·해시만 전송합니다. 메타데이터 미입력·잘못된 GPS·지원하지 않는 파일을 구분하고 수정 시각으로 촬영일을 채우지 않습니다.
- 서버는 재전송 중복·등록 중복·기기 연결 해제·만료·잘못된 Origin·미인증 요청·크기 초과를 처리합니다. 기존 PC API를 모바일로 공개하지 않습니다.
- 집 안 HTTPS 신뢰 등록과 S23 Ultra 갤러리 파일 선택 시 촬영 정보 유지가 확인되어야 입력 기능의 실사용 검증 완료로 봅니다. 외부 데이터망에서는 입력을 제공하지 않고 조회만 검증합니다.


### 집 안 입력과 외부 읽기 전용 조회

- 사진 전송은 지정한 집 안 네트워크에서만 허용합니다. 인터넷용 Caddyfile은 업로드 서버를 연결하지 않고 조회 서버만 연결합니다. Bluetooth는 보류합니다.
- 외부 조회 서버는 다른 Windows 계정으로 실행하며 원본 DB·프로젝트에 대한 파일 접근을 거부합니다. 같은 PC의 기록 API 우회 호출도 인증으로 거절해야 합니다.
- 외부에서 로그인 후 관찰·도감·소장 검색과 필터는 제공하되 관찰 저장·수정·삭제·사진 전송 경로를 제공하지 않습니다. 로그인 상태 변경은 별도 조회 인증 저장소에만 반영합니다.
- 사본은 PC에서 명시적으로 갱신하고 마지막 갱신 시각을 표시합니다. 등록된 위치·메모를 포함하는 조회 자료와 원본 SQLite 접근은 구분합니다.
- 계정별 실제 원본 파일 읽기·사본 및 실행 코드 쓰기·PC API 호출 거부를 검사합니다. 인증 없는 조회·외부 업로드·잘못된 Host/Origin·파일 경로 이탈·조회 사본 갱신도 시험 자료로 검증합니다.


모바일 사진 선택은 갤러리용 이미지 선택과 원본 파일용 일반 파일 선택을 함께 제공합니다. JPEG·PNG 검증과 전송 형식은 동일합니다. 화면에는 선택 경로와 GPS 없음·GPS 항목 오류를 구분하는 안내를 표시합니다. 같은 파일을 다른 경로로 다시 선택하면 해시 기준으로 한 항목에 선택 경로를 추가합니다. 앱은 선택기에 의해 가려진 GPS를 추측하거나 현재 위치로 대신 채우지 않습니다. 실제 기기에서 원본 파일 선택 시 GPS가 유지되는지는 별도 확인 대상입니다.

### 수집 대기 자료 정렬과 종 수정

- 종 정보 편집의 접이식 ‘iNaturalist 연결명·동종이명 후보’에서 제공자 학명·종 번호·근거·검토 상태를 확인하고 연결 사용 여부를 바꿉니다. 대표 도감 학명은 유지합니다. 자동 검색 결과를 무조건 같은 종으로 취급하지 않으며 종 구분 차이는 검토 대기로 둡니다. 사용자 지정으로 연결한 제비나비 Papilio dehaanii는 근거를 표시하고 원문 학명을 보존합니다.

- 네이처링·iNaturalist의 관찰시각 머리글 버튼으로 전체 대기 자료를 관찰 날짜·시각 오름차순 또는 내림차순 정렬합니다. 날짜 미상은 마지막에 표시합니다.
- 대기 자료를 더블클릭해 도감 종과 성장 단계를 수정합니다. 수집 원문은 보존하고 사용자 수정값을 별도로 저장하며 재수집 시 유지합니다.
- 수정값은 선택 등록에 사용합니다. 이미 등록된 기록이나 삭제된 대기 자료는 수정하지 않으며, 동시 수정 충돌은 재조회하도록 안내합니다.

### 한살이 밀도상자 표시

- 20사례 이상에서 기존 사분위수·1.5 IQR 수염을 유지하고 수염 사이 가운데 가로선을 표시용 14일 Gaussian 밀도곡선으로 대체합니다. 곡선은 기존 외곽 높이 전체를 사용하며, 사분위 구간만 채우고 밑변과 경계 세로선을 표시합니다. 곡선도 같은 단계의 선 두께·색·채움 농도를 사용합니다.
- 밀도는 중복 제거한 모든 해당 사례로 계산하되 수염 밖 곡선은 표시하지 않습니다. 이상값 점은 보존합니다. 곡선 높이는 각 단계 안에서 정규화하며 개체 수·출현 확률·세대 수를 뜻하지 않습니다.
- 연말·연초는 원형 날짜 축으로 연결합니다. 중앙값 선은 채워진 도형 내부로 제한합니다. 채워진 구간의 가로 범위가 가운데 50%이며 색칠 면적이 50%라는 뜻은 아닙니다. 도감 막대와 밀도상자는 이전보다 위 2·아래 3만큼 키우며 단계 행 높이와 점 크기는 유지합니다.
- 도감과 관찰 통계의 독립성, 20사례 미만 점 표시, 날짜·표본 단위·가중치·발생 차수를 자동 분리하지 않는 규칙은 유지합니다.


모바일 웹 사진 진단은 선택 파일의 크기·전체 SHA-256·EXIF 블록 수·GPS 디렉터리와 태그 번호·읽기 오류를 기기 화면에만 표시합니다. 전송 없이 확인할 수 있고 진단 항목은 API에 추가하지 않습니다. GPS 위도·경도와 방향 태그의 자료형·값 개수·파일 범위·분모 0 여부·분자 모두 0 여부·방향 유효성과 숫자/분·초/상한 검사를 추가로 표시합니다. 이 상세 진단에는 실제 좌표값이나 원시 방향 문자열을 포함하지 않습니다. 해시 차이만으로 위치 가림을 확정하지 않으며, 오류가 있는 경우 GPS 없음과 구분합니다. 실제 S23 Ultra에서 같은 원본의 두 선택 경로 비교는 아직 필요합니다.


### Android 집 안 사진 전송 앱 범위

사용자가 허용한 MediaStore JPEG·PNG를 12장씩 미리 보며 최대 500장 선택하고 원본 요청의 촬영 정보·GPS를 확인한 뒤 수동 전송합니다. 선택 사진 권한과 사진 위치 정보 권한은 구분하되 Android 권장 방식으로 사진·선택 사진·사진 위치 권한을 함께 요청합니다. 권한 미허용·원본 제공 불가 시 종료 대신 안내합니다. 기존 내부 HTTPS·연결 코드·최대 30일 쿠키·해시 중복 확인·PC 검수 등록을 재사용합니다. 전송은 Wi-Fi와 고정 내부 주소로 제한하고 원본·미리보기·URI는 보내지 않습니다. 전송 간격은 최소 700ms이며 429 시 중단·60초 재시도 제한, 만료·해제 시 재연결을 안내합니다. 선택과 결과는 화면 회전 시 보존하고 영구 저장하지 않으며 세션만 Keystore로 암호화합니다. 앱을 벗어나면 남은 작업을 중단하고 수신만으로 관찰을 생성하지 않습니다. S23 Ultra의 원본 GPS 접근·내부 HTTPS 인증 경계는 확인했으며 실제 사진 한 장의 전송·PC 대기함 표시·DB 재조회를 확인했습니다.

### 종 선택과 종별 입력 항목 표시

- 탐사 등록·수정의 종별 입력 항목과 개별 입력 영역 제목은 `종별 기록 번호 · 선택한 종명`으로 표시합니다. 종을 바꾸면 저장 전에도 반영하고 동정 미확정은 번호만 표시합니다. 항목 전환·추가·제거 후에도 종과 해당 입력값의 연결을 유지합니다.
- 수집 대기 자료 수정 창은 종 목록을 읽은 뒤 현재 종이 선택된 상태로 엽니다. 목록 조회 실패 시 수정 창을 열지 않고 오류를 표시합니다. 종 목록의 원래 도감 순서는 바꾸지 않으며 현재 종이 목록 위쪽에 보이도록 목록 자체를 스크롤합니다. 현재 종을 목록 앞에 복사하거나 재배치하지 않습니다.

- 관찰 등록·수정과 수집 대기 자료 수정은 공통 검색형 종 입력을 사용합니다. 국명·학명의 부분 일치로 후보를 좁히고 마우스 또는 방향키·Enter로 종을 선택합니다. Escape는 목록만 닫고, 검색어만 입력한 상태는 저장하지 않습니다. 종 미상은 허용된 관찰에서 명시적으로 지정할 수 있습니다.
- 신규 직접 관찰은 탐사 날짜를 사용하며 개별 날짜 입력을 표시하지 않습니다. 다른 날의 관찰은 별도 탐사로 등록합니다. 기존 개별 날짜는 수정 저장 시 원래 값을 유지하고 이를 안내합니다. 간접 관찰·논문 입력의 날짜와 외부 수집 원문은 유지합니다. 직접 관찰 사진의 시각 적용은 관찰 시각만 바꾸며 날짜·GPS 원문을 덮어쓰지 않습니다.

- PC 선택 목록은 단일 선택과 검색형 종 입력의 글자·행 높이·강조색을 통일합니다. 종 목록은 국명 13px·학명 11px 한 행, 항목 32px로 화면 위아래 중 여유가 큰 공간에 맞춰 10종보다 길게 표시합니다. 고정 항목 수 제한을 두지 않고 현재 종의 맨 위 스크롤을 유지합니다. 일반 단일 선택과 복수 선택 목록은 최대 높이 322px를 유지합니다. 목록은 수정 창의 영역에 잘리지 않으며 작은 화면은 높이를 줄여 화면 안에 유지합니다. 다른 단일 선택 목록은 지원 Chrome에서 같은 디자인을 사용하고 미지원 브라우저는 기본 선택 기능을 유지합니다. 체크박스 복수 선택은 동작을 유지하고 같은 목록 크기·강조색을 적용합니다.

관찰 검색은 공백으로 나눈 검색어를 모두 만족하는 기록을 찾으며 1월~12월은 실제 관찰 월로 해석합니다. #번호 단독 입력은 원본 관찰 번호와 정확히 일치시킵니다. 기존 필터는 함께 적용됩니다. 한살이 상세 사례에는 통계적 이상값을 표시하고 이상값만 보기로 좁힐 수 있습니다.

지도·기록은 같은 아이콘 필터를 사용합니다. 종 찾기는 국명·학명 입력 즉시 결과를 표시하고 선택한 종을 제거 버튼이 있는 태그로 표시합니다. 중복 선택을 막으며 검색어와 선택 조건은 구분합니다. 채집 필터는 내부 접이식 제목·배경 박스 없이 세 체크 항목을 바로 표시합니다.

화면 위치는 브라우저 로컬 저장소에 보관합니다. 마지막 탭·화면별 검색어·관찰 필터를 복원하며 편집창과 입력 중 양식은 자동 복원하지 않습니다. 도감 스크롤과 같은 관찰 목록의 스크롤을 복원합니다. 저장 실패는 화면 작업을 막지 않습니다. 지도 진입은 이전 탐사 상세 선택을 해제하며 왼쪽 종 목록은 선택 종 또는 검색 결과를 표시합니다. 지역 요약은 실제 관찰 건수가 많은 지역부터 정렬하고 동률에 검색 일치를 반영합니다.

지도 왼쪽은 상세 편집 컴포넌트 대신 종별 전체 목록과 선택한 탐사 요약 카드를 표시합니다. 요약은 날짜·장소·종·건수를 제공하고 더블클릭 또는 Enter로만 상세 팝업을 엽니다. 한살이 상세의 사례 구간 선택은 참고 구간·구간 밖을 표시용으로만 필터링하며 통계 원본을 변경하지 않습니다. 어른벌레의 지역별 최초·최후는 선택 조건 안의 월일 극값이며 실제 관찰 연도와 원본 번호를 함께 표시합니다. 통계적 이상값도 포함합니다.

간단한 후속 UI: 소장 종 선택은 공통 검색형 선택기를 사용합니다. 소지하지 않음은 기본 소장 목록에서 제외하되 상태 필터로 다시 조회하며 원본은 보존합니다. 필수 날짜·간접 출처·논문 근거와 필수 종에 빨간 별표를 표시하고 위치 대체 입력 조건을 안내합니다. 수집 행은 마우스·키보드 초점에서 노란색으로 강조하고 도감 세부정보 태그는 한 행에 하나를 배치합니다. 기본 정보 편집의 닫기는 우측 상단에 있습니다. 지도 지역별 최초·최후 표시는 사용자 보류이며 한살이 상세에 추가한 집계는 유지합니다.

자료 수집 대기함 표는 둥근 사각형 테두리 안에 표시하며 머리글을 고정하지 않습니다. 머리글은 목록과 함께 스크롤됩니다.

관찰 상세는 탐사·관찰 정보와 오른쪽 사진을 연한 노란 둥근 박스로 분리합니다. 상단은 탐사 전체 삭제·기록 수정·닫기 순서이며 기본 초점은 닫기입니다. 개별 관찰 삭제는 해당 관찰 아래쪽에 있습니다. 학명은 종명 아래, 좌표는 주소 다음 줄에 표시하고 시각은 분까지만 표시하며 저장 원문은 보존합니다. 관찰·탐사·소장 표는 밑줄 없이 한 번 클릭 선택, 더블클릭 상세 열기를 사용합니다.

도감 국명·동정 포인트 더블클릭 또는 Enter는 조회 팝업을 엽니다. 이름·대표사진·동정 포인트·기주식물·서식지·세부 정보·등록 사진 모아보기 순으로 읽고 편집 버튼으로만 편집 화면에 진입합니다. 대표사진은 이름 왼쪽과 팝업에 표시하며 단계별 동정 사진은 별도로 지정합니다. 사진 모아보기의 탐사 공통 사진이 모두 해당 종을 촬영했다는 뜻으로 해석하지 않습니다. 조회용 대표사진은 320px 이하의 작은 WebP를 지연 로딩하고, 상세는 1920px 표시 사본을 사용합니다. 원본은 보존합니다.

도감 조회 팝업의 나머지 정보는 기본 정보 한 박스에 묶지 않고 항목별 노란 둥근 박스로 표시합니다. 출처는 항목의 전체 폭에서 줄바꿈하며 좁은 다단 열로 배치하지 않습니다.

수집 논문은 즐겨찾기와 별도 논문 태그로 분류하고 태그 검색으로 좁힙니다. Gemini 서지 추출은 사용자가 선택한 공개 PDF 첫 두 쪽의 추출 텍스트 최대 12,000자를 동의 후 전송합니다. 추출에 성공하면 제목·저자·학술지·발행 연도의 유효한 값을 자동 저장하고 기존 값은 출처 이력에 보존합니다. 같은 연도의 상세 발표일은 유지합니다. Gemini 웹 검색은 응답·근거 링크·검색 제안을 화면에서 보여줍니다. 원문을 확인한 사용자는 원문 주소·제목·관련 종을 별도로 대기함에 입력하고, 관찰 근거를 직접 입력한 자료만 간접 관찰로 등록합니다. 두 Gemini 기능의 앱 호출 한도는 한국 시간 기준 하루 합계 10회입니다.

검수 등록 관리에서 성장 단계 일괄 변경을 열면 현재 페이지에서 체크한 대기 자료에만 새 단계를 적용합니다. 종 입력은 비활성화됩니다. 다른 창에서 수정했거나 이미 등록 또는 삭제된 항목이 하나라도 있으면 전체 변경을 되돌립니다.


### 수집 목록과 긴 화면의 조작

수집 목록 위와 아래에 이전·다음 페이지 이동을 제공합니다. 등록 결과 요약과 처리 상태는 수집 자료 제목 오른쪽에 두고 처리 상태의 자리를 유지합니다. 제외 사유는 펼쳐 확인합니다. 수집 중지 버튼은 가져오기 오른쪽에 두며 현재 요청 저장 후 중지하는 기존 동작을 유지합니다. 수집 행은 일정 높이로 표시하고 긴 기상·주소는 도움말 또는 원문 링크에서 확인합니다. 마우스 올림은 회색, 선택은 노란색으로 구분합니다. 필수 표시 별표는 제목과 같은 줄에 표시합니다. 나비 정보 편집은 하단에도 닫기 버튼을 제공합니다. 긴 목록·팝업은 스크롤 후 현재 영역의 맨 위로 이동하는 버튼을 제공합니다. 배경색으로 구분되는 바깥 패널과 태그 선택 박스의 테두리는 투명하게 표시하며 입력·표·팝업 경계는 유지합니다. 전체 간격과 정렬의 통일은 별도 검토 사항입니다.
