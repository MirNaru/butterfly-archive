# 화면 구성과 완료 기준

아래 내용은 확정된 목표 사양입니다. 현재는 종 수동 등록, 탐사·종별 기록 등록과 목록·상세 조회, 통합 검색·필터, 관찰 기록표와 하단 지도·표·나비 도감 탭을 구현했습니다. 환경 태그와 한살이 도표도 구현했습니다. 네이버 지도·주소 선택과 ASOS 기상 조회·저장도 구현했습니다. 탐사·종별 기록 수정과 사진·소장 관리도 구현했습니다. 탐사·관찰의 휴지통 삭제·복구도 구현했으며 사용자용 백업·복원은 보류했습니다. 데이터 의미는 [데이터 구조](data-model.md), 구현 상태와 미정 사항은 [미구현 및 확인 사항](improvement.md)을 따릅니다.

## 화면 배치와 탐색

화면의 활동 단위 명칭은 탐사입니다. 기존 데이터 호환을 위해 코드의 Survey·survey_id·surveys와 API /surveys는 그대로 사용합니다. 개인 입력 원문이나 기존 출처 메모는 용어 변경 대상으로 삼지 않습니다.

왼쪽 제목·검색·등록 버튼·하단 탭은 고정하고 노란 정보 박스만 세로로 스크롤합니다. 스크롤바는 노란 박스 밖의 흰 오른쪽 여백에 배치합니다. Chromium 계열의 세로 스크롤바는 3px로 도감 가로 손잡이 6px의 절반이며, 기본색 #fbbc04를 조정한 #d8a514 손잡이와 #fff8e1 트랙을 사용합니다. 다른 브라우저는 지원 가능한 얇은 스크롤바로 표시합니다. 왼쪽 패널의 240px 고정 폭과 버튼 간격은 유지합니다.

왼쪽 패널 하단에 지도 / 표 / 나비 도감 / 자료 수집 탭을 둡니다. 지도와 표는 같은 데이터베이스의 기록을 다른 방식으로 보여줍니다. 실제 Excel 앱이나 원본 엑셀을 열어 동기화하는 기능은 아닙니다.

- 지도 탭: 왼쪽 정보창, 오른쪽 넓은 지도입니다. 정보창에 검색·필터·목록·선택한 기록 상세를 표시합니다. 탐사 등록·수정은 중앙 창에서 진행하며 정보창 접기는 후속 범위입니다.
- 표 탭: 넓은 엑셀형 표입니다. 관찰 기록 / 탐사 목록 / 소장 목록을 선택합니다. 관찰 기록표는 국명 열 고정, 정렬·검색·필터를 지원합니다. 종 정보는 나비 도감 탭에서 조회·편집합니다.
- 탭 전환 시 적용 가능한 검색 조건과 선택한 기록을 유지합니다. 서로 다른 목록으로 전환할 때 지원하지 않는 조건을 조용히 적용하지 않습니다.
- 핀 선택 시 왼쪽에 기록을 표시합니다. 표에서 기록 선택 후 지도 전환 시 해당 위치를 보여줍니다. 좌표 미지정 기록은 표·목록에 남기고 지도 이동 불가를 안내합니다.
- 동일 위치의 여러 기록은 선택 목록으로 확인합니다. 마커 숨김·필터 변경·지도 이동으로 핀이 중복되지 않아야 합니다.

관찰 행을 더블클릭하거나 국명 버튼에서 Enter를 누르면 중앙 상세창을 열며, 기록 수정도 같은 창에서 진행합니다. 셀 직접 편집, 여러 셀 붙여넣기와 일괄 수정은 별도 범위입니다. 왼쪽 정보창은 PC에서 240px 고정 폭이며 탐사 등록·수정은 중앙 창에 공통 정보와 종별 기록을 나누어 배치합니다.

## 화면별 기능

| 화면 | 기능 |
| --- | --- |
| 기록 목록 | 탐사별 목록과 종별 보기, 새 탐사 등록, 검색·필터 |
| 등록·수정 | 날짜·장소 → 여러 종별 기록 → 사진·생태·태그 → 기상 확인 → 저장 |
| 상세 | 사진, 종·개체·채집 정보, 위치, 기상 출처, 메모와 수정 시각 |
| 종 정보 | 국명·학명, 생태·동정 메모, 기주식물, 출현 도표와 분포 참고 |
| 소장 | 암수 소지 상태, 수량, 취득 경로와 연결된 기록 |
| 설정·휴지통 | 연동 상태, 외부 조회 설정, 삭제 기록 복구. 사용자용 백업·복원은 보류 |

입력 선택 항목은 구역을 나누어 접을 수 있게 합니다. 저장 실패 시 입력 내용이 사라지지 않아야 합니다. 현재 수정 시각 표시와 모든 변경 내역의 이력 보존은 다른 기능이며, 전체 수정 이력 기능은 아직 확정하지 않았습니다.

## 검색과 통계

| 대상 | 조건 |
| --- | --- |
| 관찰 기록 | 종, 실제 관찰 기간, 지역, 단계, 성별, 발견 여부, 채집 여부, 태그, 기온과 그 출처, 동정 상태 |
| 종 정보 | 과·아과, 국명·학명, 일반 출현 시기, 기주식물, 분포 지역, 미접 여부 |
| 소장 정보 | 종, 성별, 소지 여부, 취득 경로 |

실제 관찰 날짜와 일반 출현 기간을 혼동하지 않습니다. 현장 기온과 외부 관측 기온은 구분합니다. 지도와 표에 같은 기록 조건을 적용하면 결과 건수가 일치해야 합니다. 구매·외부 목격 자료는 개인 관찰 통계에 자동 포함하지 않습니다.

## 가로형 출현 도표

가로축은 1월부터 12월, 세로축은 알·애벌레·번데기·어른벌레입니다. 단계 미확인 자료를 어른벌레으로 자동 분류하지 않습니다. 문자 요약은 36구간을 사용하지만 실제 관찰점의 날짜는 일 단위로 표시할 수 있어야 합니다.

이번 사용자가 제공한 엑셀의 출현 기간은 어른벌레 기준으로 확인되었습니다. 해당 자료는 어른벌레 행에 사용하며 다른 단계로 확장하지 않습니다.

| 표시 | 의미 |
| --- | --- |
| 옅은 가로 막대 | 엑셀·도감의 출현 참고 기간 |
| 작은 점 | 실제 관찰 사례의 날짜 |
| 상자 | 자료 조건이 충족될 때 관찰 날짜의 가운데 50% 구간 |
| 상자 안 선 | 관찰 날짜의 중앙값 |
| 수염 | 명시한 통계 규칙에 따른 범위이며 최초·최종 관찰일과 혼동하지 않게 설명 |

색상만으로 출처를 구별하지 않고 범례·문구를 함께 제공합니다. 기존 엑셀 기간만으로 사분위수나 상자를 생성하지 않습니다. 자료가 적을 때는 참고 막대와 관찰점을 우선 보여줍니다.

지역·연도·단계를 선택하여 비교합니다. 관찰 통계의 기간 선택·사분위수·수염·이상값 판정은 도감과 독립적입니다. 현재는 단계별 연간 관찰 날짜의 분포를 표시하며 도감에서 발생 차수를 자동 분리하거나 확정하지 않습니다. 빈 기간의 연속 출현을 뜻하지 않음을 안내합니다. 여러 발생 차수의 관찰 기반 분리 기준은 후속 검토 사항이며 연말·연초와 윤일은 처리합니다.

사진 장수·채집 개체 수는 관찰 빈도를 자동으로 늘리지 않습니다. 사용자 확인 또는 검수 생략 등록으로 수용된 단계 지정 관찰 사례를 날짜·장소·출처 단위로 묶고 단계별 20사례부터 선형 보간 사분위수와 1.5 IQR 수염을 표시합니다. 도감 기간 밖 관찰도 동일하게 포함하고 도감 수정·삭제가 통계에 영향을 주지 않습니다. 통계적 이상값은 점으로 보존합니다. 상세 규칙은 data-model.md에 있습니다. 조사 노력·지역 편향 보정과 자동 발생 차수 판정은 후속 범위입니다. 표시는 수집된 날짜의 분포이지 출현 확률·풍부도·실제 개체 수 분포가 아닙니다.

## 도표 상호작용

- 참고 막대에 마우스를 올리면 기간·발육 단계·출처를 보여줍니다.
- 현재 단계별 마우스 안내는 날짜·지역·출처·표본 수를 보여주며 클릭하면 전체 사례와 원본 기록 ID를 엽니다. 개별 점의 시각·개체 수·사진 미리보기와 기록 상세 바로 이동은 후속 범위입니다.
- 상자에는 집계 조건·기록 수·중앙값·범위와 관련 사례를 표시합니다.
- 클릭하면 사례 목록을 중앙 창으로 엽니다. 마우스를 유지해야만 정보를 볼 수 있는 구조로 제한하지 않습니다.
- 종 목록의 표에서도 작은 가로 도표를 제공하여 종 간 시기를 비교할 수 있도록 합니다.

## 기능별 완료 기준

| 기능 | 확인할 결과 |
| --- | --- |
| 등록·수정 | 저장 후 재조회와 서버 재시작 후 값이 유지되고 탐사·종별 기록 관계가 일치합니다. |
| 입력 검증 | 필수 누락, 잘못된 날짜·좌표·수량, 미상 값과 서로 모순되는 입력을 처리합니다. |
| 미발견 | 기록 없음, 기주식물만 확인, 대상 종 미발견을 구분합니다. |
| 삭제 | 합의한 삭제·복구 규칙을 따르고 관련 사진 원본이 자동 삭제되지 않습니다. |
| 지도·표 | 선택 연동, 동일 필터 결과, 좌표 없는 기록, 빈 결과, 중복 핀을 확인합니다. |
| 사진 | 형식·크기 검증, 실패 처리, 원본과 썸네일 구분, 촬영 정보가 없거나 다른 경우를 확인합니다. |
| 기상 | 실제 API와 모의 응답 검증을 구분하고 누락·통신 실패가 기록 저장을 막지 않습니다. |
| 출현 도표 | 구간 경계, 2월·윤년, 연말 교차, 단계 미확인, 자료 없음, 출처와 마우스·클릭 동작을 검증합니다. |
| 소장 | 구매·미확인·직접 채집을 분리하고 수량 미상을 0 또는 1로 변환하지 않습니다. |
| 백업·복원 | 사용자 요청으로 보류했으며 현재 완료 기준에서 제외합니다. |
| 성능 | 수백 건의 테스트 기록과 사진에서 환경·건수·측정 방법·결과를 기록합니다. |

외부 연동은 무료 조건과 실제 응답까지 확인해야 완료입니다. 오류·미검증·보류 사항은 완료 보고에서 구분합니다.


## 현재 지도·기상 구현 범위

- 제목과 화면 전환 탭은 왼쪽 패널에 배치합니다. PC 바깥 여백과 패널 사이 간격은 모두 12px이며 왼쪽 너비는 240px로 고정합니다. 오른쪽 일반 본문 여백은 20px입니다. 지도 화면은 좌우 12px, 상하 10px이며 지도는 남은 높이를 채웁니다. 좁은 화면에서도 바깥 여백은 12px이며 620px 이하에서는 위아래 배치를 사용합니다.
- 핀 숨기기 오른쪽에 일반지도·위성지도 전환 버튼을 둡니다. 기존 지도 객체의 유형만 바꾸며 위치·핀·선택 상태를 유지합니다. 지도·표 탭을 왕복해도 선택한 지도 유형을 유지합니다. 위성지도는 SDK의 SATELLITE 유형을 사용합니다.
- 지도 탭은 왼쪽 목록·상세, 오른쪽 지도입니다. 탐사 등록·수정은 지도와 표 모두 화면 중앙의 별도 창에서 진행합니다. 같은 좌표는 핀 하나와 기록 선택 목록으로 표시합니다. 핀 숨김은 객체를 재사용하며 지도·표 전환은 지도를 다시 생성하지 않습니다. 정보창 접기는 후속 구현입니다.
- 주소 검색은 버튼을 누를 때만 실행합니다. 좌표의 주소 확인도 별도 버튼이며 지도 이동마다 요청하지 않습니다. 주소 검색·지도 선택 후 적용 버튼으로 입력값을 반영합니다.
- 기상은 먼저 기록을 저장하고 상세에서 연결합니다. 조회 실패가 기록 등록을 막지 않습니다. 저장된 자료의 조회는 로컬 DB만 사용합니다. 현장 실측값으로 표시하지 않습니다.
- 명시적 관측소 조회·선택 후 기상을 저장하며 관찰 시각, 실제 자료 시각, 관측소·거리·출처·조회 시각·누락을 구분합니다. 시각 없는 당일 기록은 일자료 조회를 다음 날 이후로 안내합니다.
- 비용 차단은 제공자 강제 제한과 로컬 한도를 함께 사용합니다. 키·무료 적용 확인이 없으면 비활성화하며 재시도·유료 전환은 하지 않습니다. 상세 설정과 한도는 README를 따릅니다.


## 구현된 통합 검색·관찰 기록표

- 두 검색 전환 버튼 없이 왼쪽 통합 양식으로 조건을 설정합니다. 오른쪽은 관찰 기록표이며 국명·학명·장소·날짜와 선택 시각·저장 기상 다섯 열을 표시합니다. 국명은 가로 스크롤 중 고정됩니다. 나머지 결과·단계·성별·수량·채집·좌표·위치 방식·동정·메모·수정 시각은 표시 열 선택과 상세에서 확인합니다.
- 날짜·국명·관찰 개체 수 정렬을 지원합니다. 수량 미상은 방향과 무관하게 마지막이며 미발견은 해당 없음입니다. 별도 탐사 목록에서는 종별 기록이 없는 탐사를 조회합니다.
- 통합 검색은 국명·학명·장소·날짜·탐사 및 종별 메모를 대상으로 합니다. 날짜 범위는 양끝 포함이며 개별 날짜를 우선합니다. 장소, 다중 종·단계·성별·결과·채집 여부, 시각·좌표 유무, 저장 기상 연결 상태 필터를 함께 적용합니다. 같은 필터의 선택은 OR, 서로 다른 필터는 AND입니다.
- 미발견 기록은 단계·성별 필터에서 제외합니다. 빈 탐사는 종별 조건이 없을 때만 탐사 목록과 지도에 남습니다. 필터에 맞는 종별 기록만 지도 핀의 입력으로 사용하며 좌표 없는 기록 수를 별도로 표시합니다.
- 탐사 검색은 기준일, 목표 지역(등록된 분포 문자열 부분 일치), 종 검색, 현재 어른벌레 출현 참고 기간, 채집 종·북한에만 분포·미갱신 미접·보호종 제외, 남은 일수 오름차순·내림차순을 제공합니다. 종 분포로 지도 핀을 만들지 않습니다.
- 비율 분모는 등록된 전체 종 중 기준일의 출현 참고 종 수입니다. 분자는 현재 검색·제외 조건을 만족하면서 미채집이 확인되고, 보호종 아님과 목표 지역·기간의 채집 가능이 확인된 종 수입니다. 분모가 0이면 비율 박스를 빈칸으로 표시합니다. 미확인값은 분자에 포함하지 않습니다. 제외 조건은 확인된 해당 종만 제외하며 미확인 종을 임의로 분류하지 않습니다.
- 하단 화면 선택은 지도 / 표 / 나비 도감 / 자료 수집입니다. 나비 도감 탭에서는 왼쪽 공용 검색창으로 국명·학명을 검색하고 왼쪽 등록 양식으로 종을 추가합니다. 오른쪽은 국명·학명 / 한살이 기간 / 기주식물 / 서식지 / 습성 / 기타 / 동정 포인트 표로 구성합니다. 국명을 누르면 중앙 편집창을 엽니다. 분포·미접 연도·채집·보호·출처 편집도 유지합니다. 제공된 엑셀에서 국명·학명·기주식물 282종을 반입했으며 다른 생태 자료는 임의로 채우지 않습니다. 표 셀 직접 편집·일반 대량 반입은 후속 범위입니다.
- 탐사 등록·수정 창은 기존 화면을 유지한 채 배경을 약간 어둡게 표시합니다. 탐사 공통 정보와 선택한 종별 기록을 좌우로 나누며, 여러 종별 기록은 선택창으로 전환하고 입력값은 모두 보존하여 함께 저장합니다. 오류가 있는 숨겨진 항목은 자동으로 열어 안내합니다.
- 1280×720 데스크톱 기본 배율에서 직접 관찰 기본 입력 배치를 제공하며 간접 출처·오류 안내 등 추가 항목으로 공간이 부족하면 창 내부 스크롤을 허용합니다. 좁은 화면·확대 배율·오류 안내 등으로 공간이 부족하면 창 내부 스크롤을 허용합니다. 위치 선택은 보조창에서 진행하며 탐사 취소에는 작성 계속 / 저장하지 않고 닫기를 제공합니다.

나비 기본 정보의 기본 정렬은 호랑나비과 / 네발나비과 / 흰나비과 / 팔랑나비과 / 부전나비과 순서입니다. 아과와 종은 엑셀 순서를 따르며 검은눈그물나비는 뱀눈나비아과 끝, 푸른줄까마귀왕나비는 왕나비아과 끝으로 모읍니다. 기본 정보 검색은 이 순서를 유지하고 별도 정렬 버튼을 만들지 않습니다. 분류 순서 미지정 신규 종은 뒤에 둡니다.

관찰 기록 검색의 모든 필터는 여섯 아이콘 그룹으로 제공합니다. 날짜·시각, 종, 관찰 특성(결과·단계·성별), 채집, 위치(장소·좌표), 기상 조건이며 검색 규칙은 기존과 동일합니다. 각 버튼에는 이름 안내·키보드 초점·펼침 상태·적용 상태가 있습니다. 흰색과 #fbbc04 기반 테마를 적용하고 기존 기능을 유지합니다.

지도 상단 버튼은 글자 12px·세로 여백 5px로 줄이고, 핀 버튼과 지도 종류 버튼 묶음의 간격은 지도 좌우 여백과 같은 12px입니다. 일반지도·위성지도는 서로 붙인 버튼 형태이며 낮춘 높이를 유지합니다. 외부 연결 안내 문장은 지도 하단 저장 안내 영역에 표시합니다. 하단 저장 안내는 구분선 없이 기존보다 1pt 작은 글자와 절반의 세로 여백을 사용합니다. 확보한 공간은 지도 높이에 반영합니다.


## 통합 표의 출처와 참고 행 규칙

- 표의 관찰 행은 한 건당 한 행이며 여러 장소·날짜를 대표 기록 하나로 줄이지 않습니다. 기본 열은 국명·학명·장소·시간·기상입니다. 분류 순서가 기본이며 날짜·국명·개체 수·남은 출현 일수 정렬을 제공합니다.
- 직접 / 간접 관찰을 동시에 또는 개별 선택할 수 있습니다. 간접 출처 근거는 필수이며 사용자 채집 이력과 원 관찰자의 채집 기록을 구분합니다. 네이처링 확장 수집은 사용자가 시작하고 선택 등록하며, iNaturalist는 공식 API로 수집하고 사용자 선택으로 등록하며 구글링 수집은 후속 범위입니다.
- 표에서는 관찰·탐사 조건을 이름이 있는 펼침 양식으로 표시합니다. 지도에서는 여섯 아이콘과 출현·탐사 조건을 사용하며 상태를 공유합니다.
- 관찰 기록 없는 종 포함을 켜면 원본 관찰이 전혀 없는 종만 참고 행으로 표시합니다. 관찰 날짜·장소·출처·개체·좌표·기상 조건을 지정한 경우 참고 행은 제외합니다. 참고 분포는 실제 관찰 장소나 지도 핀으로 바꾸지 않습니다.
- 관찰 행은 탐사 상세·수정으로 연결합니다. 기록 없는 종 참고 행에서는 기본 정보를 열지 않으며 종 정보 조회·편집은 나비 도감에서 수행합니다. 빈 탐사 목록 보기는 기존 선택 메뉴로 유지합니다.
- 비율은 현재 검색 결과의 종을 중복 없이 집계합니다. 분모는 전체 등록 종 중 기준일의 출현 참고 종, 분자는 미채집·보호종 아님·해당 목표 지역·기간의 채집 가능이 모두 확인된 종입니다. 미확인은 분자에서 제외합니다.
- 참고자료 요청 중·실패 상태를 표시하고 다시 읽기를 제공합니다. 탐사 조건을 적용한 상태에서 참고자료를 읽지 못하면 조건을 무시한 결과를 표시하지 않습니다.

## 구현된 환경 태그

등록·수정창에서 탐사 공통 태그와 종별 추가 태그를 접고 펼칩니다. 기본 항목과 직접 추가한 이름을 체크박스로 선택하며 검색창에서 이름을 찾아 새 항목을 추가할 수 있습니다. 선택하지 않은 항목을 부재로 해석하지 않습니다. 추가 중에는 기록 저장을 잠시 막고, 실패하면 입력과 기존 선택을 유지합니다. 새 이름은 즉시 로컬 목록에 기억되며 기록 취소와 별개입니다.

출처·관찰 특성 필터 안에서 환경 태그를 검색·선택합니다. 선택 태그 중 하나 이상이면 해당 그룹에 일치하고 다른 조건과는 모두 만족해야 합니다. 관찰 기록표의 선택 열에서 환경 태그를 표시할 수 있습니다. 상세에서는 공통 태그와 개별 태그를 구분합니다. 습성은 도감에서 관리하며 자동 태그 분류나 태그 이름 변경·통합·삭제는 구현하지 않습니다.

별도 시험 DB에서 등록·수정·재조회, 새 입력에서 이름 기억, 중복·빈 이름·과다 입력, 미발견·간접 관찰, 공통·개별 복합 검색, 빈 결과, 통신 실패 후 입력 유지·재시도를 확인했습니다. 1280×720에서 태그를 접은 기본 입력 화면의 내부 세로 스크롤이 없음을 확인했습니다. 태그를 펼치면 목록 또는 창의 스크롤을 사용할 수 있습니다. 실제 지도 타일·마커 재검증은 외부 API 비용을 피하기 위해 수행하지 않았으며 로컬 필터 연결과 지도 오류 상태·핀 숨김·탭 전환만 점검했습니다.


## 구현된 나비 도감 상태 요약

국명·학명 아래에 해당 상태만 줄바꿈 가능한 태그로 표시합니다. 멸종위기 I급·II급은 옅은 적색, 천연기념물은 황갈색, 지역보호[경기도]는 주황색, 미접[2025]는 청색, 북한 서식은 보라색, 절멸은 회색 계열입니다. 색과 함께 글자로 의미를 구분하고 마우스를 올리면 출처를 표시합니다. 미접의 여러 확인 연도는 정렬해 함께 표시하며 연도 미상은 명시합니다. 태그가 없다고 해당 없음으로 확정하지 않습니다.

국명을 눌러 여러 보호 지정과 지역·출처·확인일, 북한 서식·미접·목격 연도, 국내 절멸과 출처를 편집할 수 있습니다. 상태 자료 원문·셀 출처는 편집창에서 확인합니다. 지역보호는 국가보호종 제외 필터와 구분합니다. 절멸은 국내 기준의 별도 분류이고 자동 제외 필터는 추가하지 않습니다. 큰수리팔랑나비에는 사용자 지정 절멸과 보호정보 확인 필요를 함께 표시합니다.


## 구현된 사진과 촬영 정보

- 탐사 공통과 종별 기록에 사진·촬영 정보를 따로 연결합니다. 새 탐사와 수정 화면의 사진 관리 창에서 검사·후보 확인·선택 등록을 하고 탐사 저장으로 연결합니다.
- 촬영 정보만 보관하는 것이 기본이며 증거 사진으로 선택한 파일만 data/photo에 복사합니다. 원본은 변경하지 않고 미리보기는 별도 생성합니다. 같은 파일 내용은 재사용합니다.
- 촬영 날짜·시각과 GPS는 각각 사용자가 적용해야 입력란에 반영됩니다. 탐사에는 날짜만, 종별 기록에는 날짜와 선택 시각을 적용합니다. GPS 적용 시 기존 장소명을 비우며 주소·기상 자동 조회는 하지 않습니다. 지도 사용은 기존 네이버 연동 범위를 따릅니다.
- 파일명·원문 촬영 시각·시간대·추출 좌표·기기명 등을 보존하고 촬영 정보가 없거나 잘못된 경우 명시합니다. 날짜를 파일명이나 파일 생성일로 추측하지 않습니다. 시간대 미상은 확인 경고를 표시합니다.
- 처리는 순차 진행·중단·재시도를 지원합니다. 실패한 파일과 입력은 유지하고 정상 처리한 다른 항목을 자동 삭제하지 않습니다. 파일 검사와 목록에 진행·오류·등록 상태를 표시합니다.
- 기록 상세에는 정보만 보관한 항목과 증거 사진을 구분하고 미리보기·원본 내려받기를 제공합니다. 기록에서 연결 해제하더라도 원본은 자동 삭제하지 않습니다. 보관 자료 목록에서 다시 연결할 수 있습니다.
- JPEG·PNG 정지 사진, 한 장 최대 32MiB·6000만 화소, 한 번에 2000장과 기록당 2000개 연결을 지원합니다. HEIC와 동영상은 후속 범위입니다. 목록은 12개씩 나누며 썸네일은 지연 로딩합니다. 서로 다른 원본 1400장의 브라우저 전체 처리 성능은 미검증입니다.


## 구현된 소장 목록

- 하단 표 화면의 표 종류에 소장 목록을 추가합니다. 왼쪽 공용 검색창과 소장 등록·취득 경로·소지 상태·성별 필터를 사용하고 오른쪽은 목록 표로 표시합니다. 지도·나비 도감과 기존 관찰·탐사 표 기능을 유지합니다.
- 종·성별·소지 상태·선택 수량·취득 경로·선택 날짜·직접 채집 관찰 연결·근거·메모·사진을 등록하고 수정합니다. 성별은 수컷·암컷 체크박스 중복 선택이며 둘 다 선택하면 총수량을 2개체 이상 필수 입력합니다. 성별 세부 수량은 둘 다 비우거나 총수량과 합계가 같도록 함께 입력합니다. 국명을 누르면 중앙 편집창을 열고, 원래 내역이 여러 건이면 성별 내역에서 수정할 기록을 선택합니다. 통신·검증·편집 충돌 오류가 나면 입력을 유지합니다.
- 같은 종·같은 취득 경로는 표에서 한 행으로 묶고 암수 모두 있으면 수컷 / 암컷으로 표시합니다. 원본 기록의 성별 수량·취득 근거·날짜·사진은 보존합니다. 소장 개체 수에 마우스를 올리거나 키보드 초점을 맞추면 수컷 n개체 / 암컷 m개체를 표시하며 미상은 추정하지 않습니다.
- 현재 소장 종 수·알려진 수량·수량 미상 건수를 구분합니다. 서로 다른 취득 건은 저장소에서 자동 병합하지 않습니다. 미체크·미확인·수량 미상에서 개인 채집이나 수량 1을 추정하지 않습니다.
- 구매·기타·미확인으로 개인 관찰이나 채집 이력을 만들지 않습니다. 직접 채집만 근거와 함께 과거 채집 이력 판단에 반영하며 연결 관찰의 종·출처·채집 수량을 검증합니다. 소장 사진의 촬영 날짜와 GPS는 취득 날짜·위치로 적용하지 않습니다.
- 사용자용 백업·복원은 사용자 요청에 따라 이번 범위에서 제외합니다. 기존 DB 이전의 자료 보존용 복사본 생성과 롤백 규칙은 유지합니다.

## 자료 수집 화면

- 관찰 상세의 탐사 메모와 종별 출처에 포함된 HTTP·HTTPS 원문 주소는 주소 그대로 표시하는 하이퍼링크로 제공합니다. 클릭하면 새 탭으로 열며 저장된 원문은 변경하지 않습니다.
- 탐사 등록·수정창의 입력 항목 이름은 굵게 표시하며 입력값과 보조 설명은 일반 굵기를 유지합니다. 글자 크기와 배치는 유지합니다.
- 나비 도감 오른쪽에 자료 수집 탭을 표시합니다. 왼쪽에서 iNaturalist·네이처링·구글링을 선택하고 오른쪽에서 선택한 수집처와 준비 상태를 확인합니다.
- 네이처링 확장은 연결 키로 현재 기록 및 보관 자료를 로컬 DB에 전송합니다. 수집 화면에서 25건 단위 목록을 조회합니다. 같은 관찰 번호는 중복을 방지하고 변경 전 내용을 보존합니다. 개인 탐사·지도·통계에는 자동 편입하지 않습니다. iNaturalist는 공식 API 수집·선택 등록을 지원하며 구글링은 선택 화면만 구현했습니다. 네이처링 자료는 사용자 선택 등록 후 지도·표와 조건에 맞는 한살이 통계에 반영합니다. 사진 파일의 별도 다운로드는 실행하지 않습니다.
- 네이처링 자동전송은 사용자가 누르면 시작 페이지 다음의 관찰을 끝까지 이동·추출·보관·DB 전송합니다. 상단 다음 관찰 링크의 검색 조건을 유지하며 DB 전송을 마치고 다음 링크가 준비되면 추가 대기 없이 순차 이동합니다. 팝업을 닫아도 실행되고 다시 열어 중지할 수 있습니다. 다음 링크 없음·반복 링크·다른 페이지 이동·로딩 시간 초과·추출 및 전송 실패 시 종료합니다. 확장 재로드나 브라우저 재시작 시 자동 재개하지 않습니다. 연속 전송은 사용자 Chrome에서 작동을 확인했습니다. 확장 재시작 후 자동 재개와 별도의 대량 수집 안정성 검증은 제공하지 않습니다. 게시자 위치 비공개 안내가 있으면 좌표를 읽거나 전송하지 않고 다음 관찰로 진행합니다.
- 수집 표의 행 선택과 머리글 전체 선택은 현재 페이지의 모든 자료에 적용합니다. 등록 버튼은 선택 중 등록 가능한 미등록 자료만 추가합니다. 선택 자료 등록 버튼으로 간접 관찰에 추가하며 원문과 등록 연결을 보존해 중복을 막습니다. 검토 필요·도감 추정 단계를 목록에 표시합니다. 등록된 자료는 수집 목록에서 빠지고 관찰 표·지도 자료를 다시 읽습니다. 등록된 관찰은 관찰 상세의 삭제 버튼으로 휴지통에 옮깁니다.
- 선택 자료 삭제는 확인 후 수집 목록에서만 숨기고 이미 등록한 관찰을 유지합니다. 같은 자료의 재전송으로 다시 나타나지 않습니다. 수집 화면에서 마지막 삭제를 취소할 수 있으며 원문과 이력은 DB에 보존됩니다.

## 구현된 탐사·관찰 휴지통

- 왼쪽 휴지통에서 복구합니다. 탐사 삭제는 자식 관찰을 함께 숨기며 탐사 복구 시 그 전에 따로 삭제한 관찰은 계속 숨깁니다. 개별 관찰 복구는 탐사 복구 후에 가능합니다.

### 목록·도감 표시 성능

- 탐사 목록은 같은 읽기 트랜잭션에서 탐사·관찰·태그·사진 연결을 일괄 조회하며 단건 조회와 같은 상속·출처·휴지통 제외 규칙을 적용합니다. 저장 기상 목록은 외부 호출 없이 한 번에 읽고 기존 조건 변경 표시를 유지합니다.
- 표의 자료·조건이 같으면 계산 결과와 표 화면을 재사용합니다. 상세 팝업을 여닫을 때 불필요하게 전체 표를 다시 계산하지 않습니다.
- 도감 전체 종 행과 검색은 유지하고 화면 주변의 한살이 그림만 생성합니다. 그림 공간 높이는 미리 확보하여 행이 출렁이지 않도록 합니다. 가로 스크롤 위치 변경만으로 기존 그림을 다시 계산하지 않습니다.
- 탭 사이에는 도감 자료 요청 결과를 재사용하되 도감 편집·종 등록·명시적 새로고침 이후에는 다시 읽습니다. 요청 실패는 재시도할 수 있으며 실패 결과를 영구 보관하지 않습니다. 숨긴 도감 전체 화면을 메모리에 유지하지 않습니다.

### 도감 개조식 표시와 자료 반입

- 동정 포인트는 종 구분·암수 구분을 나누고 습성·기타와 함께 개조식으로 저장합니다. 도감 표에서는 각 `-` 줄을 실제 글머리 점으로 표시합니다.

- 동정 설명에서 날개 전체의 단순 색은 `날개는 ○○색 바탕`, 상대적인 명암은 `날개 바탕색이 더 진함/연함` 형식으로 씁니다. 특정 날개·윗면·아랫면이 명시된 경우 그 범위를 유지하며, 눈·몸통·점·무늬 색을 날개 바탕색으로 바꾸지 않습니다.
