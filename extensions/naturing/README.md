# 네이처링 확장 프로그램

크롬에서 `chrome://extensions`를 열고 개발자 모드를 켠 뒤, 압축해제된 확장 프로그램 로드에서 이 폴더를 선택합니다.

관찰 상세 페이지를 열고 확장 버튼 → 현재 기록 읽기 → 원문 확인 → 확장 프로그램에 보관 순서로 사용합니다. 사진과 로그인 정보는 추출하지 않습니다. 자료는 크롬 프로필의 확장 로컬 저장소에 남으며 확장을 제거하면 삭제될 수 있으므로 필요한 자료는 내보내기로 보관합니다.

한 건 추출·미리보기·로컬 보관·JSON 내보내기·앱 DB 전송을 제공합니다. 다음 관찰이 끝날 때까지의 자동전송을 추가했습니다. 갱신 경계와 본문 동정 검증은 미구현입니다. 한 건 DB 전송은 실제 크롬에서 확인됐으며 횟수 제한 없는 자동전송은 크롬에서 추가 확인이 필요합니다.

## DB 연결

1. 크롬 확장 관리 화면에서 새로고침하여 버전 0.4.1을 적용합니다. 로컬 서버와 네이처링 접근 권한을 확인합니다.
2. 앱의 자료 수집 → 네이처링 → 크롬 확장 프로그램 연결에서 연결 키를 발급합니다.
3. 확장의 앱 연결 설정에 키를 붙여넣고 저장합니다.
4. 현재 기록 DB 전송 또는 보관 자료 DB 전송을 누릅니다. 서버 주소는 127.0.0.1:8000입니다.
5. 앱에서 목록 새로고침을 누릅니다.

키 재발급은 이전 키를 만료시킵니다. 전송 실패 후 재시도해도 동일 기록 번호는 중복 생성하지 않습니다. 변경 전 자료는 DB 이력으로 보존합니다. 팝업을 닫으면 여러 건 전송이 중단될 수 있으며 다시 전송할 수 있습니다. 연결 키는 JSON 내보내기에 포함하지 않습니다.

## 연속 자동전송

네이처링 검색 결과에서 관찰 상세 페이지를 연 뒤 `자동전송 · 끝까지`을 누릅니다. 시작 페이지는 제외하고 상단의 다음 관찰 링크로 이동한 각 관찰을 추출·보관·DB 전송합니다. 링크에 붙어 있는 검색 조건을 그대로 사용하며 사진 넘김 화살표는 사용하지 않습니다. 검색 조건 없는 상세 페이지는 사이트가 제공하는 전체 관찰 순서를 따르므로 검색 결과에서 시작해 주세요.

DB 전송 완료 후 다음 링크가 준비되면 추가 대기 없이 이동합니다. 동시에 여러 페이지를 요청하지 않습니다. 다음 링크 없음, 반복 링크, 예상 외 페이지, 페이지 로딩 시간 초과, 추출·전송 오류가 발생하면 멈춥니다. 자료는 검토 대기로 저장하며 사진 파일은 별도 다운로드하지 않습니다. 다만 관찰 페이지를 여는 과정에서 사이트의 사진·지도는 브라우저에 표시될 수 있습니다.

이전·다음 링크는 본문 로드 후 비동기로 표시되므로 최대 20초 기다립니다. 이전 링크만 표시되면 다음 관찰이 없는 것으로 처리합니다. 탐색 영역이 계속 비어 있으면 마지막 페이지로 단정하지 않고 로딩 오류로 중단합니다.

자동전송은 백그라운드에서 실행되어 팝업을 닫아도 계속됩니다. 다시 열면 진행 상태와 중지 버튼을 볼 수 있습니다. 중지는 다음 이동·전송을 막지만 이미 서버에 도착한 요청은 저장됐을 수 있습니다. 브라우저 재시작·확장 재로드 후 자동으로 다시 실행하지 않습니다. 실행이 중단된 경우 현재 페이지를 확인한 뒤 수동으로 시작하세요. 재시작은 현재 페이지의 다음 기록부터 진행되므로 실패한 현재 기록은 먼저 개별 전송할 수 있습니다.

횟수 제한은 없으며 이전 링크만 남으면 종료합니다. 접근 차단이나 요청 제한 응답이 나타나면 중단하며 우회하지 않습니다.

새 패키지는 사용하지 않습니다. `node --test extensions/naturing/background.test.cjs`는 실제 사이트와 개인 DB에 접근하지 않는 모의 테스트입니다.

게시자가 위치를 비공개로 한 기록은 현재 기록 읽기·보관 자료 DB 전송·연속 자동전송에서 제외합니다. 비공개 안내가 있으면 지도 DOM에 좌표가 남아 있어도 읽지 않습니다. 연속 수집은 다음 관찰로 계속 진행하고 완료 문구에 위치 비공개 제외 건수를 표시합니다. 단순히 좌표가 없다는 이유만으로 비공개로 추정하지는 않습니다.
